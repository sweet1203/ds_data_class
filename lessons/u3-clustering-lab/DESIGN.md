**확인할 점** (화면에서 바로잡거나 밝힘)
- **ows 설정 확인**(148쪽 `.ows`를 오렌지3 3.40 파이썬으로 열어 확인): File Role — CustomerID·Gender·Age meta, Annual Income·Spending Score feature / k-Means — optimize_k(From 2 to 8), **Normalize columns 켜짐**, KMeans++ 초기화, Re-runs 10, Max iterations 300, 고른 줄 k=5 / Scatter Plot — x Annual Income, y Spending Score, Color Cluster / Silhouette Plot — Euclidean, Cluster, Bar width 1. 설정 표에 그대로 씀.
- **ows의 연결 Data Table →(Selected Data) k-Means**: 3.40 Data Table은 줄을 고르지 않으면 데이터 전체를 내보내므로 교과서 연결 그대로 그림. 줄을 누르면 고른 줄만 넘어가므로 설정 표 3번 줄과 「막혔을 때」에 「Data Table에서 줄을 눌러 고르지 마세요」를 적음.
- **오렌지3 3.40으로 계산 확인**(Normalize + KMeans++ + random_state 0, 위젯과 같은 코드): 실루엣 k=2 0.286 · 3 0.467 · 4 0.494 · **5 0.555** · 6 0.538 · 7 0.526 · 8 0.457(교과서 149쪽 0.555와 같음). k=5 군집: C1 81명(가운데, 0.598) · C2 39명(소득·지출 높음) · C3 35명(소득 높고 지출 낮음) · C4 23명(둘 다 낮음) · C5 22명(소득 낮고 지출 높음). 이 맥 실행에서 18번은 C5, 188번은 C2 — **교과서는 각각 C2·C3**이라 군집 이름이 교과서와 다르다(설계안 확인할 점). 화면은 위치로 말하게 하고(cl-warn, 퀴즈 5-3), 교과서 이름은 「교과서는 … C2, … C3이라고 불렀어요」로만 밝힘.
- **Data Table의 Silhouette 열**: 오렌지3 3.40 k-Means는 실루엣 계수 s를 `arctan(s)/π + 0.5`로 바꾸어 0~1 값으로 내보낸다(owkmeans.py). Silhouette Plot의 값(−1~1)과 숫자가 달라 설정 표 6번 줄에 「0~1 사이로 바꾸어 보여 주는 값이라 Silhouette Plot의 숫자와 달라요」라고 적음.
- **Role 이름**: 교과서 148쪽 「ignore」는 3.40 Role 목록에서 「skip」. Role 카드에 함께 적음.
- 148쪽 「연관 소득과 지출 점수만 feature로 설정한 이유」의 「연관」은 「연간」의 오타. 화면은 「연간 소득」.
- 149쪽 Tip 「항상 낮지 않고 … 항상 높지 않은」은 극단어지만 교과서 문장이라 화면에 옮기지 않고, 설정 표 4번 줄에 「소득이 낮은데 지출 점수가 높은 무리, 소득이 높은데 지출 점수가 낮은 무리를 찾아요」로 씀.
- 150쪽 「5개 그룹의 실루엣 계수는 0.5~0.6 사이」: 계산하면 0.505~0.599로 맞음.
- 150쪽 스스로 해결하기와 본문 Tip이 「지출 점수를 정렬」/「연간 소득을 정렬」로 서로 다르게 말함. 설정 표는 「지출 점수(또는 연간 소득)로 정렬」로 둘 다 허용.
- 파이썬(152~153쪽)은 정규화 없이 묶어 0.5539, 오렌지3는 정규화 후 0.555 — 04 접기에 차이를 밝힘. 파이썬 군집 번호(0~4)도 오렌지3 이름과 다름.
