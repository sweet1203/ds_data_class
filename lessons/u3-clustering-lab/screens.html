01

데이터 불러오기와 속성 확인하기

교과서 148쪽 · 고객 쇼핑 데이터셋 · Role(역할) · feature를 두 속성으로 정한 까닭 · Visualize numeric values

쉽게 말하면오렌지3에 파일을 불러오면 속성마다 역할(Role)을 정해야 해요. 군집을 나누는 데 쓸 속성은 feature, 쓰지 않고 참고로만 볼 속성은 meta로 정해요. 오늘은 연간 소득과 지출 점수 두 속성으로만 고객을 묶어요.

📂 준비 · 고객 쇼핑 데이터셋

선생님이 알려 주는 폴더에서 Mall_Customers.csv를 내려받아요. 캐글에서 「Mall Customer Segmentation Data」라는 이름으로 공개된 고객 200명의 쇼핑 데이터예요.

속성뜻값의 모습
CustomerID고객 ID1부터 200까지 고객마다 붙인 번호
Gender성별Male, Female
Age나이18~70세
Annual Income (k$)연간 소득천 달러 단위, 15~137
Spending Score (1-100)지출 점수쇼핑몰이 매긴 1~100점, 클수록 많이 쓰는 고객

🏷️ Role(역할) 종류

meta

분석에 쓰지는 않지만, 참고하려고 표에 보여 주는 속성

feature

분석에 영향을 주는 원인이 되는 속성

target

예측하고자 하는 결과가 되는 속성

ignore

무시해도 되는 속성. 오렌지3 3.40의 Role 목록에서는 skip이라는 이름이에요.

💡 연간 소득과 지출 점수만 feature로 정한 까닭 · 고객의 쇼핑 패턴을 비교적 뚜렷하게 나누어 보려고, 두 속성으로 2차원 그림을 그려 확인하기로 했어요. 나이(Age) 같은 다른 속성을 feature에 더하면 군집 결과는 지금과 달라져요.

🗂️ 역할 정하기 (5장 · 속성을 보고 역할 고르기)

🔎 데이터 속성 확인하기

  1. File 위젯에 Data 카테고리의 Data Table 위젯을 연결해요.

    데이터가 표로 보여요. 왼쪽 Info에서 데이터 개수와 결측치가 있는지 확인해요.

  2. 「Visualize numeric values」를 체크해요.

    feature로 정한 숫자 칸에 값의 크기만큼 막대가 그려져, 고객끼리 값의 크기를 쉽게 비교할 수 있어요.

02

군집 수 정하고 군집 확인하기

교과서 149~150쪽 · 오렌지3 실습 · k-Means · Scatter Plot · Silhouette Plot · Data Table

쉽게 말하면k-Means 위젯이 k를 2부터 8까지 바꿔 가며 묶어 보고 실루엣 점수를 알려 줘요. 점수가 가장 큰 k를 골라 군집을 만든 뒤, 산점도로 모양을 보고 Silhouette Plot으로 군집마다 얼마나 잘 묶였는지 확인해요.

🔀 위젯 연결 흐름도 (위젯을 누르면 아래 설정 표의 그 줄이 강조돼요)

04

(선택) 파이썬으로 해 보기

교과서 152~153쪽 · KMeans · silhouette_score · silhouette_samples · 군집 시각화

쉽게 말하면오렌지3로 한 분석을 파이썬 코드로 똑같이 해 볼 수 있어요. 시간이 남거나 집에서 더 해 봐요.

🐍 코랩에서 실행하기

  1. 선생님이 알려 주는 노트북을 열어 「사본 만들기」를 해요.

    교과서 노트북을 수업에 맞게 고친 사본이에요.

  2. ➊ 데이터 업로드하기

    업로드 셀을 실행해 Mall_Customers.csv를 고르거나, 왼쪽 파일 창에 먼저 끌어다 놓았다면 바로 아래 /content/Mall_Customers.csv를 읽는 셀만 실행해요.

  3. ➋ 실루엣 계수로 군집의 수(k) 정하기

    k를 2부터 10까지 바꾸며 묶고 실루엣 점수가 가장 큰 k를 찾아요. np.argmax()는 목록에서 가장 큰 값의 위치를 알려 줘요.

  4. ➌ 실루엣 계수 시각화하기 → ➍ 군집 위치 확인하기 → ➎ 결과 시각화하기

    k마다 점수를 꺾은선으로 그리고, k = 5로 묶어 고객마다 군집 번호를 붙인 뒤 산점도를 그려요. 오렌지3 Scatter Plot과 모양을 비교해요.

  5. ➏ 실루엣 계수 계산하기

    전체 실루엣 점수와 군집별 평균 실루엣 계수를 구해, 오렌지3 Silhouette Plot의 괄호 안 값과 비교해요.

교과서 코드와 달라진 점 · 비교할 때 주의할 점
  • 파일 읽기 셀 추가: 파일 창에 먼저 올린 경우를 위한 셀을 넣었어요. 업로드 셀과 둘 중 하나만 실행해요.
  • 변수 이름: ➏에서 실루엣 점수를 silhouette_k5에 담아, ➋의 점수 목록을 덮어쓰지 않게 했어요. ➌ 그래프를 다시 실행해도 오류가 나지 않아요.
  • 범례 순서: ➎에서 군집 번호를 작은 것부터 그려요.
  • 군집 번호: 파이썬은 0~4, 오렌지3는 C1~C5로 이름을 붙이고, 같은 무리라도 번호가 서로 달라요. 위치로 비교해요.
  • 점수 차이: 오렌지3 k-Means는 열을 정규화(Normalize columns)한 뒤 묶어서 0.555, 파이썬 코드는 원래 값으로 묶어서 0.5539가 나와요.
