# u1-review 설계표 — 협력적 창의·융합 활동 · Ⅰ단원 정리 (교과서 54~57쪽, 10쪽 단원 핵심 질문)

50분 한 차시에서 모둠이 「나의 상식을 데이터로 확인하기」(54~55쪽)를 하고, 진로 인터뷰(56쪽)를 읽은 뒤 Ⅰ단원을 정리한다(57쪽). 모둠 활동이지만 메모는 각자 화면에 적는다(질문폼은 개인).

퀴즈 13문항(정답 위치 ①5 ②5 ③3). 질문폼(data-u1-review) 1번 ← 01 `ox1~3`·`oxWhy` + 02 `probPick`·`resultNote`·`reasonNote`, 2번 ← 02 `reasonNote` + 03 `regret`·`nextPlan`(평가 영역 「데이터 과학의 필요성 이해」와 같은 물음), 3번 ← 03 `career`.

**50분 흐름** (화면 0 「50분 계획」과 같음) — 모둠 정하기 · 상식 확인(8분) O/X 투표와 근거 → **02 데이터로 검증하기(15분, ~23분)** 기술자가 사이트를 열고 질문 2로 축 맞추기 연습 → 모둠이 고른 문제 확인 → 결과 분석·이유 토론(접속이 안 되면 접어 둔 토론 안내로) → **03 진로 · 성찰(9분, ~32분)** 인터뷰 카드·진로 메모 6분(~29분), 성찰 메모·자기 평가 3분 → 04 단원 정리(8분, ~40분) 빈칸 4개·퀴즈 → 마무리(10분) 핵심 질문 ① 답(②는 선택)·퀴즈·질문폼. 질문폼 1번 근거는 23분 안, 3번(진로)은 23~29분, 2번의 성찰 메모는 29~32분에 닿음. 발표는 시간이 되는 모둠만 하거나 다음 시간 앞부분에(선생님 운영).

**줄인 것** — 54쪽 「수행 계획서」 QR은 넣지 않음. 모둠원 역할 분담 표는 「나의 역할」 칩 하나로 줄임. 54쪽 Gapminder 그래프 화면 캡처는 넣지 않고 「읽는 법」 그림을 새로 그림(점 위치는 실제 데이터가 아님). 55쪽 동료 평가 5~1 표는 접어 둔 메모 한 칸으로 바꿈(실제 발표 뒤에 쓰도록). 56쪽 인터뷰는 문장을 그대로 옮기지 않고 요약해 다시 씀. **57쪽 단원 정리 1~12번 문항과 QR 형성평가는 옮기지 않음** — 같은 개념을 새 상황 문장으로 써서 빈칸 6개와 퀴즈(04 3문항 · 마무리 3문항)에 넣음. 서술형 12번(데이터 기반 의사 결정)은 마무리의 단원 핵심 질문 ① 답하기로 대신함.

**확인할 점**
- **O/X 답**: 교과서는 질문 2만 본문에서 답을 줌(54쪽 「질문 2에 대한 답은 ‘O’이다」). 질문 1·3의 답과 해설은 지도서 144쪽에 있음(정답 해설이라 화면·이 문서에 옮기지 않음). 화면에서는 질문 2만 교과서 그림 읽기로 공개하고, 1·3은 모둠이 데이터로 확인하게 둠. 정리할 때 선생님이 지도서 해설로 짚어 주세요.
- **질문 3의 「고등학생」**: 지도서 그림의 세로축은 「Math achievement」로, Gapminder에서 고를 수 있는 수학 성취도 지표가 어느 학년 학생의 점수인지 교과서에 나와 있지 않음. 화면 5단계에 「지표 설명에서 몇 년의, 누구의 데이터인지(몇 학년 학생의 점수인지) 확인」을 넣어, 질문과 데이터의 대상이 다를 수 있음을 스스로 확인하게 함. 수업 전에 사이트에서 어떤 지표가 보이는지 확인해 주세요.
- **Gapminder 화면 안내**: 축 이름을 눌러 지표 바꾸기, 재생 버튼·연도 막대, 지표 검색(earthquake · math)은 일반적인 사용법으로 썼고 사이트 구성이 바뀔 수 있음을 화면에 적음. 지진 사망 지표는 사이트에서 찾기 어려울 수 있으니(지표 이름 미확인) 미리 확인해 주세요. 주소는 화면에 쓰지 않음.
- 10쪽 단원 핵심 질문 두 개는 「54쪽 ‘협력적 창의·융합 활동’에서 이 물음들을 해결해 보자」로 이어지므로 시작 화면에서 보여 주고 마무리에서 답하게 함.
- `lesson.json` tag와 표지 tag를 「데이터 과학 · Ⅰ. 데이터 과학의 이해 · 협력적 창의·융합 활동 · 단원 정리」로 맞춤.
- 55쪽 평가 기준 문장은 평가표라 그대로 둠.

**지어낸 것(예시 표시)**
- 02 「거품 그래프 읽는 법」 SVG의 거품 위치·크기·색(화면에 「실제 데이터가 아니에요」 표시).
- 04 빈칸 4개와 퀴즈 상황(동아리 학번, 매점 판매 × 날씨, 급식 만족도, 카페 매출, 태풍 시뮬레이션, 아이스크림 판매량, 혈액형, 수강 신청 · 과목 코드, 급식 관리 자료, 매점 설문)은 새로 만든 문장.
- 0 시작의 모둠명 예 「숫자 탐정단」.

**검토 반영(1차)**
- 04 빈칸 5번(응원 영상 · 대화방 → 비정형 데이터)이 57쪽 단원 정리 3번과 짜임·답이 같아 지움. 분량도 줄여 빈칸을 6개 → 4개로(비정형 데이터 · DBMS 문항을 뺌. DB는 마무리 퀴즈 2번에 남음).
- `probChips` 보기 글자에 ` · `가 있어, 저장 뒤 다시 불러올 때 칩 선택이 복원되지 않던 버그를 고침(「질문 1: 지진에 의한 사망」 꼴로).
- 50분 분량: 03에서 진로 카드·진로 메모를 성찰·자기 평가 앞에 둠(질문폼 3번 근거를 30분 안으로). 화면 이름도 「진로 · 성찰」로 바꾸고 표지 목록·50분 계획을 맞춤. 마무리 단원 핵심 질문은 ① 필수, ② (선택).
- 퀴즈 2-2 줄기를 「왼쪽 아래에서 오른쪽 위로 이어지는 모양으로 놓여 있다면」으로 고침. 5-3 오답을 그럴듯한 장점 꼴(「재고 관리가 필요 없어진다」 「학생들의 취향이 한 가지로 모인다」)로 바꿔 내용을 알아야 고를 수 있게 함.
- 질문폼 1번(작업자료 `forms/u1-review.json`)과 마무리 화면 안내를 「내가 처음 고른 O/X」 → 「그 문제에 대한 내 처음 생각」으로 바꿈(새 상식을 고른 모둠도 답할 수 있게).
- 02 사이트 안내: 「대한민국(South Korea)」을 함께 쓰고, 선 그래프 메뉴 이름은 「Trends」 같은 이름일 수 있다고 단정 없이 적음.
- 03 연구원 소개 문단을 한 문장으로 줄여 다시 씀.
- 03 `regret`·`nextPlan`의 저장 표시(.saved)를 각 메모 칸 안으로 옮김.
- O/X 투표·칩 기록은 학번별 키(`MK` + `WHO.sfx`)에 저장됨을 확인함.

**검토 반영(2차)**
- 04 빈칸 3번 줄기의 「순서의 의미가 있는」이 답(순서형)을 드러내서, 「불만족 → 보통 → 만족 → 매우 만족처럼 높고 낮음을 견줄 수 있는」으로 바꿈.
- 퀴즈 5-1 오답 「스키마」를 「칼럼」으로, 5-3 보기를 짧은 것 → 긴 것 순서로 맞춤(정답 위치 ①5 ②5 ③3).
- 메모 모아 보기에서 「(선택)」 항목은 쓴 것만 보이게 함(u1-future와 같은 방식).
- 03 자기 평가·동료 평가 표는 학생 스스로 하는 점검이라 그대로 둠(총괄 결정).
