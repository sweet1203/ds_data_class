**확인할 점** (화면에서 바로잡거나 밝힘)
- **220쪽 SSE 정의**: 옆 설명 「실젯값과 예측값 차이의 제곱에 대한 합」(본문 OCR의 「창」은 「차」)은 회귀식 정의라 군집에 맞지 않음. 군집의 SSE는 각 점과 소속 군집 중심 사이 거리의 제곱합(sklearn `inertia_`) → 01 카드와 퀴즈 1-1에서 바로잡음(PDF 49쪽 확인).
- **220쪽 k 선택**: 실제 자료로 계산(세 지표, `n_init = 10, random_state = 42`, 고친 노트북 결과) — SSE k = 2~9: 9.795 · 6.451 · 5.238 · 4.565 · 3.961 · 3.393 · 3.025 · 2.680, 실루엣: 0.458 · 0.452 · 0.446 · 0.308 · 0.310 · 0.299 · 0.284 · 0.289. 교과서 그래프(PDF 49쪽)도 실루엣이 k = 2에서 가장 높고 k = 3이 거의 같음. 「k = 3에서 SSE 감소가 완만해지므로 최적」만으로는 근거가 한쪽이라, 화면은 두 지표가 다를 수 있음을 밝히고 학생이 두 근거로 k를 고르게 함(교과서 k = 3을 정답으로 강제하지 않음).
- **220쪽 코드** `KMeans(n_clusters = k, max_iter = 1000)`에 random_state가 없어 실행마다 결과가 조금씩 달라질 수 있음(원본 노트북은 `random_state = 42`만 있고 n_init 없음) → 고친 노트북은 `n_init = 10, random_state = 42` 고정.
- **221·223쪽 군집 번호**: k-평균 k = 3 결과(실제 자료): 29개 나라(child_mort 중앙값 4.8, income 중앙값 43200) · 102개(18.4, 11150) · 36개(95.5, 1695). 번호는 실행마다 바뀌며(이 맥 sklearn 1.5.2·1.9.1에서는 0 = 중간, 1 = 사망률 낮음, 2 = 높음으로 교과서와 다름) 순위가 아님 → 02 c2-warn·sorter·퀴즈 2-2. 병합적 군집(ward): 49개(5.5, 36200) · 83개(19.8, 9720) · 35개(97.4, 1660), 번호는 0 = 낮음, 1 = 높음, 2 = 중간으로 교과서 223쪽과 같음. 두 결과 교차표에서 23개 나라가 갈림(k-평균 중간 → 병합 낮음 20, 중간 → 높음 1, 높음 → 중간 2).
- **224쪽 지도 코드 두 가지 오류**: ① 223쪽에서 병합적 군집 1 = 「도움이 필요함」이라 해 놓고 224쪽 코드는 1 → 'Might Need Help', 2 → 'Help Needed'로 바꿈(손으로 짝지은 매핑이 결과와 어긋남). ② Class 값은 'No Need Help'로 바꾸는데 color_discrete_map 키는 'No Help Needed'라 초록색이 적용되지 않음(222쪽 k-평균 코드는 키가 맞음). 화면 03 점검 카드·퀴즈 3-2, 고친 노트북은 `name_clusters()`로 중앙값 순 이름 붙이기 + 이름 통일.
- **221쪽 해석·222쪽 지도 해석**: 「도움이 필요 없음을 의미한다」, 파키스탄·아프가니스탄을 「전쟁과 내전의 영향」으로 설명한 부분은 이 데이터에 없는 원인 추정 → 03 한계 카드에 「원인은 다른 자료로 확인」으로 밝힘. 자료가 과거 어느 때의 것이고 인구 수가 없다는 한계도 함께.
- **오렌지3 3.40 확인**(위젯 모듈 소스와 Orange 라이브러리 계산): k-Means(Unsupervised) 기본은 From 2 to 8·Normalize columns 켜짐·KMeans++·Re-runs 10·Max iterations 300·random_state 0, 실루엣이 가장 큰 줄을 자동으로 고름 → 설정 표에 From 2 to 9, Normalize columns 끄기(이미 0~1), k = 3 줄 직접 누르기를 적음. 같은 설정으로 계산한 실루엣: k = 2 0.458 · 3 0.452 · 4 0.446 · 5 0.401 · 6 0.346 · 7 0.296 · 8 0.300 · 9 0.291(k ≥ 5는 random_state에 따라 노트북 값과 다름), k = 3 군집 크기 102·36·29로 노트북과 같음. Normalize columns를 켜 두면 실루엣이 0.359 · 0.394 · 0.401…로 달라져 「막혔을 때」에 확인 항목으로 넣음. Cluster·Silhouette 열은 meta로 붙고 Box Plot·Distributions에서 고를 수 있음.
