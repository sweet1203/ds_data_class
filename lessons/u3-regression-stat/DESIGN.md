**확인할 점** (화면에서 바로잡음)
- **136쪽 「p-값 의미」 옆 설명**: 「p-값 > 0.05 … 귀무가설이 맞다는 의미이다 → 집값이 독립 변수에 영향을 받지 않는다」 → 04 화면에서 「귀무가설을 기각할 수 없다(영향이 있다고 말할 근거가 부족하다). 귀무가설이 맞다고 증명된 것은 아니다」로 바로잡고 note로 밝힘(설계안 확인할 점 2). 퀴즈 4-2·ml 4-1도 이 읽기로.
- **137쪽 「중간 소득의 회귀계수(coef) 값이 가장 크고 … 가장 큰 영향」**: 결과표에서 longitude −4.263e+04, latitude −4.245e+04로 절댓값이 median_income 4.054e+04보다 크고, 계수는 변수 단위(도·개·명·만 달러)에 따라 크기가 달라 바로 비교할 수 없음 → 04에 「계수 크기 비교는 조심」 callout(보임) + 「왜 이 말을 덧붙였을까?」(접기)에서 근거. 화면 해석은 「양의 계수 + p<0.05 → 소득이 높은 지역일수록 집값이 높은 경향」까지만(설계안 확인할 점 3).
- 134쪽 코드 주석 「훈련용과 데스트용」 오타는 화면에 옮기지 않음(짝짓기 묶음 이름은 「훈련용·테스트용」).
- 135쪽 info() 출력의 ocean_proximity Dtype `object`는 pandas 3 이상에서 `str`로 보임 → 02 note에 한 줄.
- const(−3.578e+06)를 「모든 독립 변수가 0일 때 주택 가격의 기본값」(137쪽)이라고만 하면 음수 집값으로 오해할 수 있어, 「실제로 모든 변수가 0인 지역은 없어 직선의 높이를 맞추는 역할로 본다」를 풀이에 덧붙임.
