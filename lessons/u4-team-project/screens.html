모둠 역할 · 나는?
  • 팀장 질문을 정하는 토의를 이끌고 시간을 챙겨요.
  • 기술자 데이터 파일을 열고 오렌지3 설정을 맡아요.
  • 기록자 설계 보드와 결정한 까닭을 기록해요.

교과서는 「팀장, 기술자, 기록자 등」이라고 했어요. 모둠 인원에 따라 역할을 합치거나 나눠도 돼요.

핵심 질문
  • 데이터 과학과 문제 해결 · 데이터를 활용하여 문제를 어떻게 분석하고 해결할 수 있을까?
  • 오늘의 질문 · 우리 모둠이 고른 주제를 데이터로 풀려면 어떤 속성과 분석 방법, 평가 지표가 필요할까?
배우고 나면 할 수 있는 것
  • 데이터 과학으로 문제를 해결하기 위해 데이터를 수집하고 탐색적으로 분석할 수 있다.
  • 문제 해결을 위해 수집한 데이터를 데이터 과학 프로젝트 단계를 바탕으로 수행할 수 있다.
01

주제 고르기와 문제 정의

교과서 194쪽 · ① 문제 정의 · 문화 · 반려동물 · 스포츠 세 주제와 데이터셋

쉽게 말하면좋아하는 주제인지와 함께, 그 데이터로 확인할 수 있는 질문이 나오는지 보고 골라요. 모둠이 함께 하나를 골라요.

🗂️ 세 주제 가운데 하나 고르기

행·열 수는 교과서 자료실 원본 파일을 미리 세어 본 값이에요. 파일은 선생님이 알려 주는 폴더에 있어요.

주제를 고르면 그 데이터의 주요 속성이 여기에 보여요.

💭 막연한 바람 → 데이터로 확인할 질문 (새 예시 · 학교 매점)

막연한 바람데이터로 확인할 질문필요한 속성결과를 쓸 사람
매점이 덜 붐볐으면 좋겠다.쉬는 시간마다 판매 건수가 얼마나 다를까?시각, 판매 건수, 요일매점 운영 담당 선생님

질문에는 비교할 대상(쉬는 시간마다)과 잴 수 있는 값(판매 건수)이 들어 있어요. 우리 주제에서도 이렇게 바꿔 봐요.

02

데이터 점검과 시각화 계획

교과서 194~195쪽 · ② 데이터 준비(데이터 개수 · 속성 개수 · 결측치 · 이상치) · ③ 데이터 분석(분석 내용과 시각화 방법)

쉽게 말하면분석을 시작하기 전에 데이터가 우리 질문에 적합한지 점검해요. 그리고 어떤 그래프로 무엇을 볼지 미리 정해요.

🔎 데이터 점검 카드 (우리 주제 탭을 눌러 확인)

원본 파일의 개수·빈칸·값의 모습을 미리 세어 정리한 요약이에요. 실제 행은 싣지 않았어요. 앞 시간 데이터 점검실의 기준(정확성 · 통일성 · 중복 · 출처)도 떠올려요.

04

설계 공유와 성찰

교과서 195쪽 · ⑤ 성찰 · 프로젝트 수행 과정 평가하기 · 새롭게 알게 된 점 정리하기

쉽게 말하면다른 모둠에게 우리 설계를 설명하고 질문을 받아요. 받은 질문에서 우리 설계의 약한 곳을 찾아 고쳐요.

🔁 모둠끼리 설계 바꿔 듣기

  1. 우리 설계를 한 줄로 설명해요.

    설계 보드의 「우리 설계 한 줄」을 읽고 고른 까닭을 덧붙여요.

  2. 듣는 모둠은 질문을 하나 해요.

    예: 「그 속성으로 그 질문에 답할 수 있나요?」 「그 지표가 좋게 나오면 무엇을 알 수 있나요?」 「빠진 데이터는 어떻게 하나요?」

  3. 받은 질문과 고칠 점을 기록해요.

    바로 답하기 어려운 질문일수록 다음 단계에서 확인할 거리가 돼요.

✅ 지금까지의 과정 점검 (우리 설계가 이미 해낸 것을 모두 골라요)

🚀 확장 · 프로젝트 끝까지 해 보기 (오렌지3)

설계대로 데이터를 열어 시각화하고, 모델을 만들어 평가해요. 남는 시간이나 다음 활동에서 모둠이 함께 해요. 우리 설계에 맞는 줄만 따라가요.

번호위젯 (카테고리)어디에 연결설정 · 할 일확인할 것
1File (Data)처음 위젯선생님이 알려 주는 폴더의 우리 주제 파일 열기Info의 데이터 개수와 속성 개수가 점검 카드와 맞는지
2Group by (Transform)File →집계가 필요할 때만. 예: 반려동물 시설을 구·시설 종류별로 묶어 개수(Count) 만들기, 공연 예매를 연령대·장르별로 묶기새로 생긴 개수 열의 이름. 숫자가 아닌 열에 자동으로 고른 집계(Mode 등)는 필요 없으면 해제
3Column Statistics (Data)
옛 이름 Feature Statistics		File(또는 Group by) →속성마다 분포·빈칸 비율 보기결측치(Missing)가 많은 열, 값이 한쪽으로 몰린 열
4Select Columns (Transform)File(또는 Group by) →설계 보드대로 결과 속성은 Target, 사용할 속성은 Features, 번호·이름·주소는 Metas보드에서 고른 속성과 같은지
5Distributions · Scatter Plot · Box Plot (Visualize)Select Columns →02에서 세운 시각화 계획 두 가지 그리기그래프에서 본 것 한 줄씩 기록
6Linear Regression (Model)회귀분석일 때기본값 그대로Test and Score에 연결했는지
7Test and Score (Evaluate)Select Columns(Data) · Linear Regression →Test on test data: Select Columns 뒤에 Data Sampler(Transform, 70:30)를 두고 Data Sample → Data, Remaining Data → Test Data로 연결. 또는 Cross validation. Test on train data는 쓰지 않기학습에 쓰지 않은 데이터에서 잰 MSE · R² 값과 그 뜻
8k-Means (Unsupervised)군집 분석일 때Number of Clusters: From 2 to 8, Normalize columns 체크실루엣 점수가 가장 큰 k
9Silhouette Plot (Visualize)k-Means →Grouping: Cluster군집마다 실루엣 계수, 군집 특성 해석

진행 체크

  • 문화 파일이 너무 커요 → 원본은 약 366만 행(1GB 정도)이라 열기 어려워요. 선생님이 기간을 줄여 준 파일을 써요.
  • 반려동물 파일이 열리지 않아요 → 이름은 .xls지만 속은 .xlsx 형식이에요. 선생님이 확장자를 .xlsx로 바꿔 준 파일을 써요.
  • 스포츠 파일이 둘이에요 → 금액·키·몸무게가 숫자로 바뀐 CLEAN 파일이 다루기 쉬워요. 금액 단위 표기가 원본과 다른 점은 점검 카드에서 확인해요.
  • Test and Score에 값이 안 나와요 → Select Columns에서 Target을 정했는지, 결과 속성이 숫자인지 확인해요.
