01

데이터 통합은 어떻게 할까?

교과서 74쪽 · 데이터 통합 · 공통된 열 · 표 Ⅱ-5 · 수평적·수직적 통합 · 표 Ⅱ-6 형식 변환

쉽게 말하면따로 있는 두 표를 공통된 열(예: 연도)을 기준으로 한 표로 합치는 것이 데이터 통합이에요. 그런데 연도를 적는 방식이 다르거나, 같은 줄이 두 번 있거나, 빈칸이 있으면 줄이 엉뚱하게 맞춰져요. 그래서 합치기 전에 정리부터 해요.

🔗 데이터 통합

여러 개의 데이터셋 또는 파일을 통합하는 작업을 데이터 통합이라고 한다.

각 데이터셋이 다른 정보나 속성을 담고 있을 때 두 데이터를 합치면 더 많은 정보를 얻을 수 있어요. 그러면 통계적으로 더 의미 있는 결과를 얻고 더 정확하게 분석할 수 있어요. 데이터는 주로 공통된 열을 기준으로 통합해요.

📝 통합할 때 필요한 정리

데이터를 통합할 때는 중복 제거, 결측값 처리, 형식 변환 등이 필요할 수 있어요. 표 Ⅱ-5에서는 1986~1988년 해수면 높이가 결측치라서 그 기간의 해수면 온도 데이터도 지우고, 연도가 일치하는 데이터만 통합해요.

두 데이터의 형식이나 범위가 다르면 통합하면서 일관성을 유지하는 데 시간과 노력이 많이 들어요. 또 잘못된 매핑(엉뚱한 줄끼리 짝짓기)이나 중복 처리 오류가 생길 수 있어 조심해야 해요.

02

값의 범위가 다르면 어떻게 비교할까?

교과서 75쪽 · 데이터 스케일링 · Min-Max 정규화 · Z-Score 표준화 · 이상치의 영향

쉽게 말하면1989~1996년 해수면 높이 편차는 −2.5~0.5쯤, 온도 편차는 −1.0~0.1쯤이라 범위가 달라요. 이대로 함께 분석하면 범위가 큰 속성의 영향이 너무 커질 수 있어요. 데이터 스케일링은 여러 속성의 값을 비슷한 범위로 맞추는 일이에요. 값의 순서는 그대로 두고 눈금만 바꾸어요.

📏 데이터 스케일링

데이터셋에 다양한 데이터가 있을 때 각 값의 범위가 다르면 특정 데이터의 영향이 과도하게 커질 수 있어요. 이때 필요한 것이 데이터 스케일링이에요. (데이터 스케일: 데이터 값의 크기나 범위, 데이터 간의 상대적 크기)

정규화 · 최소-최대 정규화(Min-Max Scaling)

xscaled = x − xminxmax − xmin

각 값에서 최솟값을 뺀 뒤 최댓값과 최솟값의 차이로 나누어요. 최솟값은 0, 최댓값은 1이 되어 모든 값이 0~1 사이에 놓여요.

이상치가 있으면 정규화된 값의 분포가 왜곡될 수 있어요. 그래서 정규화 전에 이상치를 먼저 처리해요.

표준화 · Z-Score 표준화

xscaled = x − x̄σ

각 값에서 평균(x̄)을 뺀 뒤 표준편차(σ)로 나누어요. 평균은 0, 표준편차는 1이 돼요.

표준편차는 값들이 평균에서 얼마나 흩어져 있는지 나타내는 값이에요(뒤에서 자세히 배워요). 표준화도 이상치의 영향을 받을 수 있지만, 정규화에 비해 이상치로 인한 영향이 적은 경우가 많아요. Min-Max는 최솟값·최댓값 두 값으로 정해져 이상치 하나에 범위 전체가 좌우되고, 표준화는 모든 값의 평균·표준편차로 정해져 데이터가 많으면 영향이 덜해요.

오렌지3에서는 Preprocess 위젯의 Normalize Features 안에 Standardize가 들어 있어요. 다음 시간에 수면 데이터를 표준화할 때 써요.

🔍 표준화하면 분포의 모양이 바뀔까?

히스토그램은 값을 일정한 구간으로 나누어, 구간마다 값이 몇 개 있는지 막대로 나타낸 그래프예요. 아래 예시 데이터를 표준화하면 히스토그램의 모양은 어떻게 될까요? 먼저 예상을 골라요.

03

데이터 시각화는 무엇이고 어떤 방법이 있을까?

교과서 76~77쪽 · 시간 시각화 · 분포 시각화 · 관계 시각화 · 공간 시각화

쉽게 말하면숫자 표만 보고는 의미를 찾기 어려워요. 그래프로 바꾸면 흐름, 퍼진 모양, 두 값의 관계, 위치가 한눈에 보여요. 무엇을 알고 싶은지(분석 목적)에 따라 알맞은 그래프를 골라요.

📊 데이터 시각화

수치나 통계 데이터를 그래픽으로 표현하여 분석 결과를 직관적으로 이해할 수 있도록 돕는 기술을 데이터 시각화라고 한다.

데이터의 패턴, 추세, 상관관계 등을 쉽게 파악하고, 분석 목적에 따라 다양한 시각화 방법을 골라 의사 결정에 활용할 수 있어요.

01 시간 시각화

시간의 흐름에 따라 데이터가 어떻게 변하는지 보여 줘요. 일정한 시간 간격으로 모은 시계열 데이터에 써요.

예: 분기별 물가 변동, 연도별 해수면 높이 · 추세와 패턴 파악, 이상치 감지

02 분포 시각화

데이터의 전체적인 구조나 분포를 보여 줘요. 데이터가 일정 간격에 걸쳐 어떻게 퍼져 있는지 알 수 있어요.

예: 시험 점수 분포(히스토그램), 여러 그룹의 키 분포(박스 플롯)

03 관계 시각화

두 개 이상의 변수 사이의 연관성이나 규칙을 탐색해요. 히트맵은 상관관계를 색상의 강도로 나타내요.

예: 키와 몸무게(산점도), 판매량과 광고비(히트맵) · 산점도 행렬, 평행좌표 플롯

04 공간 시각화

정보를 지도 위에 나타내 지점마다 데이터를 비교하거나 구분해요. 위치와 거리를 바탕으로 이해해요.

예: 인구 분포·밀집도(점 지도), 지역별 출산율(등치 지역도)

그림은 모양을 보여 주려고 새로 그린 예시예요. 히스토그램은 연속된 값을 구간으로 나누어 막대 사이에 빈칸이 없고, 막대그래프는 항목마다 막대를 따로 세워 막대 사이에 빈칸이 있어요.

🎯 이 질문엔 어떤 시각화? (새로 만든 질문 8개)

질문을 읽고, 그 질문에 답하기 알맞은 시각화 방법을 골라요.

🏪 (선택) 같은 데이터, 다른 그래프 (학교 매점 4주 판매 기록 · 지어낸 예시 · 시간이 남으면)

같은 매점 데이터도 어떤 그래프로 그리느냐에 따라 보이는 것이 달라요. 그래프를 하나씩 눌러 보세요.

04

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

해수면 높이 표와 온도 표는 연도를 YYYY 형식으로 맞추고 중복 줄과 결측치가 있는 연도를 정리한 뒤에야 연도마다 한 줄씩 맞게 합쳐졌다. 공통된 열로 묶으면 한 행에서 두 속성을 함께 볼 수 있다.
범위가 다른 높이 편차와 온도 편차도 Min-Max 정규화로 0~1에, 표준화로 평균 0·표준편차 1에 맞추면 나란히 비교할 수 있다. 한 값이 이상치가 되면 나머지 값이 한쪽으로 몰리므로 스케일링 전에 이상치부터 처리한다.
표준화를 해도 히스토그램의 모양은 그대로이고 가운데 위치와 눈금만 바뀐다. 그래프는 알고 싶은 것에 맞춰 고른다. 흐름은 선 그래프, 퍼진 모양은 히스토그램과 박스 플롯, 두 값이 함께 변하는지는 산점도, 지역 사이의 차이는 지도가 잘 보여 준다.
