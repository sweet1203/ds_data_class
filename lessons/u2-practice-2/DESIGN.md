## 검토 반영(1차)
- **「10줄 · 15개 속성」(심각)**: 앞 차시 Group by에서 범주형 Mode 체크를 풀지 않았으면 「- Mode」 열이 더 보임 → 설정 표 14번 「(- Mode 열이 보이면 빼고 세어요)」, 흐름도 14번 상자 「15속성(Mode 열 빼고)」, 퀴즈 2-3 줄기 「(- Mode 열을 빼고) 15개 속성」, 「5분 안에 다시 만들기」에 범주형 Mode 체크 풀기 단계와 「- Mode 열이 보이면」 확인 추가.
- **50분**: 03은 질문폼 근거(메모 2칸 → 스스로 해결하기 표)를 위에 모으고 화면 안 산점도·조심할 점을 뒤로. 02의 Append columns 비교는 「(더 알아보기)」 접기로(기본은 Find matching pairs). 01 지수 카드 4장 → 2장. 04 위쪽에 「오렌지3 Heat Map과 화면 히트맵 중 하나는 꼭, 다른 하나는 시간이 되면」 안내, `heatWhy`는 어느 쪽을 보고 써도 되게.
- **통합 따라 해 보기 안내**: 「Merge Data 뒤에 붙인 Data Table(통합 결과 10줄)」로 위치를 말하고 「위젯 번호(예: Data Table (4))는 달라도 괜찮아요」 한 줄.
- **Correlations 설정**: 「Pearson correlation 그대로, 그 아래 선택 상자(처음에는 (All combinations))에서 …」로, 스스로 해결하기 안내도 같은 말로.
- **심화 Choropleth**: 짝을 못 찾은 나라(UnitedKingdom처럼 붙여 쓴 이름 등)는 Geocoding 창 오른쪽 목록에서 직접 고르라는 한 줄.
- **퀴즈 단서**: 4-3(정규화 1 해석 — 4-2 해설이 답을 줌)을 「Heat Map에서 줄 옆에 도시 이름을 붙이는 설정(Row Annotations)」으로 바꿈, 4-2 해설을 일반 규칙 대신 대입 설명으로, 「Min-Max」 → 화면 표기 「최소-최대 정규화」. 2-2 해설이 6-1(가게 이름 표기) 답이 되던 문제 → 6-1을 「두 표를 통합할 때 꼭 함께 있어야 하는 것(학생을 구별하는 같은 속성)」으로 바꿈. 3-3 답과 같던 조심할 점 카드 문장을 「점이 10개뿐이면 무슨 일이 생길지 한 도시를 가려 보며 생각해 봐요」로. 6-2 보기 순서 조정. 정답 위치 ①5 ②4 ③5.
- 01 「숫자가 클수록 비싼 도시」 → 「생활비·임대료·식료품·레스토랑 지수는 숫자가 클수록 그 항목이 비싼 도시」.
- **히트맵 체크 상태**: 02에서 생활비 지수를 지워 10개가 안 되면 히트맵 선택에서 생활비 지수를 자동으로 풀어 체크 표시와 계산이 어긋나지 않게 함. 화면 산점도의 r 설명 끝에 「말로 푼 부분은 대략적인 표현」 한 줄(총괄 결정: 기준은 유지).
- 위젯 이름은 「Column Statistics(교과서·옛 버전 이름은 Feature Statistics)」로 병기(고친 노트북 주석 포함). 113 노트북의 좌표 표 셀·한글 변수 이름·Geo (선택) 화면은 그대로(총괄 결정).
