퀴즈 12문항(정답 위치 ①4 ②4 ③4). 질문폼(data-u1-data-science) 1번 ← 0 시작 마시멜로 투표·`mallowWhy`, 2번 ← 02 패러다임 분류 게임, 3번 ← 03 `insD~insW`·표 Ⅰ-2 짝짓기(04 실종 아동 메모는 덧붙이기 자료).

**50분 흐름** — 시작(8분) 단원 도입은 Q 2개·여는 질문만 짚고, 마시멜로 실험 읽기 → 투표 → 반론 → `mallowWhy`(`planLearn`은 선택) → 01(7분) 브라헤·케플러 궤도 3단계, 오늘날 공공 데이터(한 줄 상자), 정의, 정의 문장 짜기 → 02(8분) 네 패러다임 카드, 분류 게임, `paraNote` → **03(23분 무렵 시작, 12분)** 벤 다이어그램(2분) → 혈압·내 데이터 4칸(28분 무렵까지) → 스마트 농업, 짝짓기 → 04(6분) 실종 아동 사례 메모·점검 → 마무리(7분) 퀴즈·질문폼. 질문폼 근거 활동(마시멜로·패러다임·내 데이터 4칸)은 30분 안에 모두 지나가고, 04 메모는 3번에 덧붙이는 자료.

**줄인 것** — 12쪽 「점검해 보기」(데이터 수집 방법 짝짓기, 교과서에 정답이 함께 실림)는 넣지 않음. 12~13쪽 만화·삽화는 옮기지 않고 이야기로 풀어 씀. 13쪽 「역량 키우기」 안내(30쪽 정리)는 04차시 몫이라 넣지 않음. 21쪽 「주요 개념 정리하기」 문장은 빈칸으로 만들지 않음(공개 저장소). 단원 도입은 짧게(문단 1개 + Q 카드 2장 + 여는 질문 1줄).

**확인할 점**
- 13쪽 「1960년 스탠포드 대학교에서는 … ‘마시멜로 실험’을 진행했다」: 교과서와 지도서(103쪽)는 「1960년」으로 적었지만, 미셸(W. Mischel)의 스탠퍼드 만족 지연 실험은 1960년대 후반~1970년대 초에 이루어진 연구로 알려져 있음(대표 논문 1970·1972년). 총괄 결정으로 화면에는 「1960년대」로 씀. 학교 이름 표기는 교과서대로 「스탠포드」.
- 12쪽 「점검해 보기」 정답 줄이 교과서에 그대로 인쇄되어 있음(텍스트 추출본 「➊-㉢, ➋-㉠ …」). 활동으로 쓰지 않음.
- 16쪽 그림 Ⅰ-1에서는 「기계 학습」, 디지털 샘의 Tip·본문에서는 「기계학습」으로 띄어쓰기가 다름. 화면(벤 다이어그램·퀴즈)에서는 본문 표기 「기계학습」으로 통일.
- 16쪽 그림 Ⅰ-1의 「통계적 연구」, 「데이터 처리」는 교과서에 따로 뜻풀이가 없음. 벤 다이어그램 설명에서는 「어느 두 분야가 겹치는 곳」이라고만 쓰고 새 정의를 만들지 않음.
- 17쪽 스스로 해결하기 출처 주소는 화면에 쓰지 않고 「교과서에 기사 출처가 있어요」로만 둠.
- 설계안 「교과서에서 확인할 점」 1~6은 이 차시 범위(12~17쪽)에 해당하는 것이 없음.

**지어낸 것(예시 표시)**
- 01 궤도 그림: 원·타원·관측 점의 위치는 모양을 과장해 새로 그린 것(화면에 「과장해서 그렸어요」 표시). 실제 관측 값이 아님.
- 01 정의 조각 게임의 섞인 조각 「느낌과 경험에 따라」, 「데이터를 보관만 하여」.
- 02 분류 게임 카드 8장(공 굴리기, 씨앗, 태풍·날씨 시뮬레이션, 검색 기록, 쇼핑 기록 등)은 새로 만든 문장. 「사과와 달」 카드는 만유인력의 법칙을 풀어 쓴 것.
- 03 「내 데이터로 이어 보기」 입력칸 안내 문구의 걸음 수 예(데이터·정보 칸만 예를 들고 지식·통찰 칸은 비워 둠).
- 퀴즈 3-1의 체온계 「38.5℃」 상황.

**검토 반영(1차)** — 질문폼 근거가 30분 안에 오도록 03의 「데이터에서 통찰까지」·「내 데이터로 이어 보기」를 스마트 농업 앞으로 올리고, 01 「오늘날에는?」 카드를 한 줄 상자로 줄임. 시작의 `planLearn`과 04의 `valCare`는 (선택)으로 표시. 「브라헤는 평생 혼자 데이터를 모았지만」을 「맨눈으로 직접 관측해 데이터를 모았지만」으로 바로잡음. 퀴즈 1-1 오답 「코페르니쿠스가 세운 원운동 가정」(1-3 답의 단서)을 「컴퓨터로 돌린 시뮬레이션 결과」로, 1-2는 줄기를 「분석하는 방식」으로 바꾸고 보기 셋을 「~으로/~대로」 같은 꼴로 맞춤. 지도서 15쪽 유의점(패러다임은 대체가 아니라 확장)을 02 카드 아래 한 문장·분류 게임 정리·key3·질문폼 2번에 반영(「바뀌어 온」 → 「더해지며 넓어져 온」). 분류 게임 이론 카드의 「여러 번 관찰한」을 빼고 실험 카드의 「기록한다」를 「살펴본다」로 고침. 벤 다이어그램 「연구 분야의 전문 지식」 설명에서 교과서 밖 내용(가설·해석, 농업·의료·기후 예)을 빼고 16쪽 문장 범위로 씀. 02에 `paraNote` 한 줄 메모 추가(MEMOLIST 포함). key3 첫 문장을 21쪽 주요 개념 정리하기 ➊과 다른 문장으로 풀어 씀. 내 데이터 4칸의 「저장됨」 표시를 각 입력칸 안으로 옮김.

**검토 반영(2차)** — 02 「쉽게 말하면」과 퀴즈 5-2 해설의 「바뀌어 왔다」를 「더해지며 넓어져 왔다」로 고침. 03 부제 순서를 화면 순서(관련 분야 → 혈압 → 스마트 농업 → 해결 가능한 문제)에 맞춤. 벤 다이어그램·퀴즈 3-2의 「기계 학습」을 본문 표기 「기계학습」으로 통일. MEMOLIST에서 `paraNote`를 화면 순서 자리(02, `insD` 앞)로 옮김.
