단원 도입 · Ⅰ. 데이터 과학의 이해 (10~11쪽)

이 단원에서는 데이터 과학의 개념을 이해하고, 이를 바탕으로 데이터 기반의 합리적인 의사 결정 과정을 배워요. 데이터의 속성을 분석해 잠재적 가치를 발견하고, 데이터 통합의 중요성과 의미를 알아봐요. 또 데이터가 사회에 미치는 변화를 이해하고, 데이터로 문제를 해결한 사례를 살펴보며 자신의 진로를 탐색해요.

2. 데이터의 저장과 활용

데이터를 효율적으로 관리하는 방법과 그 필요성은 무엇일까?

🌏 단원을 여는 질문 합리적인 의사 결정을 위해 데이터에 기반한 이해가 필요한 사회에서, 데이터 과학은 복잡한 문제를 해결하는 데 어떻게 활용될까요? 이 물음들은 단원 끝 「협력적 창의·융합 활동」에서 해결해요.

🍡 세상을 바꾸는 데이터 · 마시멜로 실험 (12~13쪽)

1960년대 스탠포드 대학교에서 3~5세 아이들을 대상으로 「마시멜로 실험」을 했어요. 자기 통제력과 인내심을 재려는 실험이었고, 마시멜로 먹는 것을 잘 참은 아이들의 자기 통제력이 강하다는 결론이 나왔어요. 이 결론을 바탕으로 다양한 학습 프로그램과 교육 방침이 만들어졌지요.

여러분은 이 분석 결과를 그대로 믿을 수 있나요? 하나를 골라 보세요.

그런데… 이 실험은 주로 부유한 가정의 아이들을 대상으로 했을 가능성이 커서, 모든 아이에게 일반화하기 어렵다는 지적을 받았어요. 후속 연구에서는 마시멜로 실험에서 나타난 참을성이 개인의 성격보다 경제적 안정성과 실험 환경에 대한 신뢰에 크게 좌우된다는 결과도 나왔어요. 경제적 배경이 실험 결과에 영향을 미쳤을 가능성을 놓친 거예요.

👉 그래서 데이터를 분석할 때는 분석 대상과 배경을 정확히 이해하고, 결과를 과장하거나 성급히 일반화하지 않는 것이 중요해요.

01

데이터 과학은 무엇일까?

교과서 14~15쪽 · 브라헤와 케플러, 데이터 과학의 개념

쉽게 말하면데이터 과학은 데이터를 과학적으로 분석해서 세상의 규칙(법칙)을 찾고, 거기서 얻은 지식과 통찰로 앞으로 일어날 일을 내다보는 학문이에요. 400여 년 전 케플러가 바로 이런 일을 했어요.

🔭 데이터 과학으로 문제를 바라본다면? (14쪽)

  1. 1543년 · 코페르니쿠스

    지구가 태양을 중심으로 1년 주기로 돈다는 지동설을 주장했어요. 하지만 천체가 태양을 중심으로 원운동을 한다고 가정했기 때문에, 천동설보다 천체 예측 결과를 정밀하게 설명하지 못했어요.

  2. 티코 브라헤

    아직 망원경이나 렌즈가 나오기 전, 시력이 좋은 브라헤는 눈으로 천체를 직접 관측해 방대하고 정밀한 천체 관측 데이터를 남겼어요.

  3. 요하네스 케플러(1571~1630)

    스승 브라헤가 관측한 데이터를 기반으로, 천체가 태양을 중심으로 한 타원 궤도를 따라 움직인다는 케플러 제1법칙을 발표했어요.

궤도 모양은 알아보기 쉽게 과장해서 그렸어요.

🏛️ 오늘날에는? (14쪽) 브라헤는 맨눈으로 직접 관측해 데이터를 모았지만, 지금은 공공 기관이 쓰던 데이터가 데이터 공유 사이트로 공개되어 누구나 활용할 수 있어요. 기상청 단기 예보 데이터와 농업 기상 관측 데이터로 만든 「작물의 최적 환경 분석을 위한 데이터 분석 플랫폼」은 공공 데이터 공모전에서 나온 사례예요.

📘 데이터 과학이란? (15쪽)

데이터 과학(data science)은 데이터를 과학적 방법으로 분석해 보편적인 진리나 법칙을 찾아내고, 쓸모 있는 지식과 통찰을 얻어 앞으로 일어날 일을 예측하는 학문이에요.

데이터 과학과 융합한 분야로는 통계학, 컴퓨터 과학, 인공지능 등이 있어요.

🧩 정의 문장 다시 짜기

위의 정의를 가린 채, 조각을 순서대로 눌러 문장을 완성해요. 정의에 없는 조각도 2개 섞여 있어요.

02

데이터 과학은 어떻게 등장했을까?

교과서 15쪽 · 과학 연구의 네 가지 패러다임

쉽게 말하면패러다임은 쉽게 말해 「사고방식」, 곧 문제를 해결하거나 세상을 이해하는 데 쓰는 기본적인 방법이에요. 과학자들이 세상을 연구하는 방법은 도구가 발전할 때마다 새 방법이 더해지며 넓어져 왔고, 그 네 번째가 데이터 과학이에요.

🪜 데이터 과학의 등장 (15쪽)

데이터 과학은 데이터의 수집, 처리, 분석 및 활용 방법이 발전함에 따라 다양한 분야와 융합되어 형성되었어요. 아래 카드를 왼쪽부터 읽어 보세요.

제1패러다임

🔬 실험 과학

자연 현상 설명

16세기 이전에는 자연 현상을 이해하려고 관찰과 실험을 활용한 연구가 제한적으로 이루어졌어요.

실험 과학의 연구 방법은 점차 발전해 훗날 데이터 과학의 기초가 되었어요.
제2패러다임

💡 이론 과학

현상을 수학적 모델링 및 일반화

자연 현상을 수학적 모델로 표현하고 추론해 현상을 설명하고 예측해요. 뉴턴의 만유인력의 법칙, 아인슈타인의 상대성 이론처럼 공식이 있는 과학 법칙이 나왔어요.

지금도 과학의 핵심 이론으로 활용되고 있어요.
제3패러다임

🖥️ 계산 과학

복잡한 현상을 가상화

20세기 중반 컴퓨터가 등장하면서 컴퓨터 시뮬레이션이나 알고리즘을 활용하는 연구로 발전했어요.

시뮬레이션을 활용한 기상 예측과 유전자 분석은 실험이나 이론으로는 해결하기 어려웠던 문제의 해결 방법을 주었어요.
제4패러다임

📊 데이터 과학

데이터 중심 현상 분석 및 미래 예측

4차산업혁명으로 데이터가 만들어지는 양과 속도가 폭발적으로 증가했어요.

인공지능과 같은 기술의 발전으로 데이터 과학이 새로운 과학 연구 패러다임으로 떠올랐어요.

➕ 새 패러다임이 나왔다고 앞의 방법이 사라진 것은 아니에요. 실험·이론·계산은 지금도 쓰이고, 그 위에 새 방법이 더해지며 연구 방법이 넓어져 왔어요.

2016년 클라우스 슈바프가 말한 4차산업혁명 물리 세계, 디지털 세계, 생물 세계가 융합되어 경제와 사회의 모든 영역에 영향을 미치는 새로운 산업 시대예요. 단순히 기기와 시스템을 연결하고 스마트화하는 데 그치지 않고, 유전자 염기 서열 분석, 나노 기술, 재생 가능 에너지, 양자 컴퓨팅 등 여러 분야에서 거대한 발전이 동시에 일어나고 있어요.

🎯 어느 패러다임의 연구일까?

연구 장면을 읽고 알맞은 패러다임을 골라요. 「무엇으로」 연구하는지(눈과 손, 수학 공식, 컴퓨터 속 가상 세계, 쌓인 기록)를 살펴봐요.

03

데이터 과학은 어디에 쓰일까?

교과서 16~17쪽 · 관련 분야, 혈압, 스마트 농업, 해결 가능한 문제

쉽게 말하면데이터 과학은 혼자 하는 학문이 아니에요. 컴퓨터 과학, 수학과 통계, 그 분야를 깊이 아는 전문 지식이 함께 있어야 해요. 그렇게 데이터에서 얻은 지식과 통찰로 전염병, 기후 변화, 자연재해 같은 큰 문제도 풀어요.

🔵 데이터 과학의 관련 분야 (16쪽 그림 Ⅰ-1을 다시 그림)

데이터 과학은 데이터를 효과적으로 다루기 위해 프로그래밍 언어와 알고리즘 같은 컴퓨터 과학 및 IT, 데이터 분석을 위한 수학과 통계, 각 연구 분야의 전문 지식 등 다양한 학문과 밀접하게 연결되어 있어요. 그림의 원이나 겹친 곳을 눌러 보세요.

🩺 데이터에서 통찰까지 (17쪽)

데이터 과학은 문제 해결뿐 아니라 데이터에서 유의미한 지식과 통찰을 끌어내 미래를 예측하거나 계획을 세우는 데도 쓰여요.

데이터「혈압 수치」
→
정보「160/100(mmHg)」
→
지식「혈압이 매우 높다」
→
통찰「운동과 채식을 병행해야겠다」는 의사 결정

혈압은 수축기 혈압과 이완기 혈압 두 수치로 재고, 밀리미터 수은(mmHg) 단위로 나타내요. 160/100이면 160이 수축기 혈압, 100이 이완기 혈압이에요. 이 통찰은 운동 계획을 세워 실천하는 디딤돌이 되기도 해요.

✍️ 내 생활 속 데이터로 이어 보기 혈압 말고 다른 데이터를 하나 골라 네 단계로 이어 봐요.

🌱 데이터 과학으로 문제를 해결한 사례 (16쪽 표 Ⅰ-1)

2023년 창업 경진 대회에서 우수상을 받은 「AI 디지털 트윈 스마트 농업 플랫폼」은 공공 데이터와 센서로 수집한 데이터로 제어 시스템을 만들면, 작물 생육의 최적 상태를 유지하는 환경을 구성할 수 있다는 가설을 세웠어요. 그 뒤 데이터를 수학과 통계 방법으로 검증하고, 컴퓨터 과학으로 분석해 인공지능 원격 제어 시스템을 개발했어요.

① 가설 수립현장 센서, 기상 데이터, 토양 데이터, 작물 데이터로 실시간으로 작물 생육의 최적 상태를 유지하도록 환경을 구성할 수 있다.
→
② 데이터 검증 및 통합· 수집된 데이터의 정확성과 일관성을 검증한다.
· 다양한 형식의 데이터를 통합한다.
→
③ 일정한 법칙 도출작물의 생육 밸런스를 맞추는 알고리즘 분석 기술을 개발했다.

가설 · 어떤 사실을 설명하거나 이론 체계를 끌어내려고 세운 가정이에요. 연구 문제에 대해 미리 내놓는 예측적인 답이지요.

이처럼 데이터 과학에서는 가설을 세우고 → 데이터로 검증한 뒤 → 일정한 법칙을 도출해요. 다양한 데이터로 모델과 결과의 신뢰성을 확인하고, 이를 실제 의사 결정이나 업무에 반영하지요. 각 단계마다 전문 지식, 수학 및 통계학, 컴퓨터 과학, 기계학습 같은 이론과 기술이 쓰여요.

🔗 데이터와 해결할 문제 짝짓기 (17쪽 표 Ⅰ-2)

왼쪽에서 데이터를 하나 누르고, 오른쪽에서 그 데이터로 해결할 수 있는 문제를 눌러 짝을 지어요.

사회 각 분야에서 데이터가 폭발적으로 늘면서 교육, 의료, 금융, 제조, 경영 등 다양한 영역에서 데이터 과학이 적극 활용되고, 그 범위는 빠르게 넓어지고 있어요. 이처럼 데이터 과학은 인류의 지속 가능한 삶을 위해 꼭 풀어야 하는 문제에서 중요한 역할을 하는, 우리 사회의 여러 문제를 해결하는 데 꼭 필요한 도구예요.

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

케플러가 브라헤의 관측 데이터에서 타원 궤도의 법칙을 찾았듯이, 데이터 과학은 데이터를 과학적으로 분석해 세상의 규칙을 찾고, 거기서 얻은 지식과 통찰로 앞으로 일어날 일을 내다보는 학문이다.
과학 연구 방법은 실험 과학 → 이론 과학 → 계산 과학 → 데이터 과학의 네 가지 패러다임으로 발전했다. 앞의 방법은 사라지지 않고, 새 방법이 더해지며 넓어졌다. 데이터가 만들어지는 양과 속도가 폭발적으로 늘고 인공지능 같은 기술이 발전하면서 데이터 과학이 새로운 패러다임으로 떠올랐다.
데이터 과학은 컴퓨터 과학/IT, 수학과 통계, 연구 분야의 전문 지식이 함께 쓰이는 분야로, 가설을 세우고 데이터로 검증해 법칙을 도출한다. 데이터 → 정보 → 지식 → 통찰로 나아가며 전염병·기후 변화·자연재해·에너지 같은 사회 문제 해결에 쓰인다.
