01

데이터 모델이란 무엇일까?

교과서 124~125쪽 · 데이터 모델 · 데이터 모델링 · 정답(레이블) · 표 Ⅲ-1

쉽게 말하면데이터 모델은 데이터 속 패턴·관계·구조를 찾아 예측하거나 묶어 주는 방법이에요. 어떤 모델을 쓸지는 「데이터에 정답(레이블)이 있나?」와 「알아내고 싶은 값이 숫자인가 범주인가?」로 정해요.

🧩 데이터 모델과 데이터 모델링

데이터 모델

데이터를 이해하고 그 안에서 정보를 뽑아낼 때 쓰는 여러 방법이나 기술이에요. 데이터의 패턴, 관계, 구조를 나타내고, 이것으로 예측·군집·연관분석 같은 일을 해요.

데이터 모델링

데이터를 잘 이해한 뒤 알맞은 모델을 골라 만드는 과정이에요. 데이터와 분석 목적에 맞는 모델을 고르고 적용해야 쓸모 있는 결과가 나와요.

모델마다 쓰는 데이터의 종류, 분석 목적, 결과를 평가하는 방법이 달라요(교과서 125쪽). 그래서 데이터의 특성과 문제에 맞는 모델을 골라야 해요.

03

데이터 분석에 필요한 지표

교과서 128쪽 · 더 알아보기 · 평균 제곱 오차 · 정확도 · 실루엣 계수 · 지지도·신뢰도·향상도

쉽게 말하면모델을 만든 뒤에는 「분석이 제대로 되었나?」를 숫자로 확인해요. 이 숫자가 평가 지표예요. 모델마다 목적이 다르니 쓰는 지표도 달라요. 어떤 지표는 작을수록, 어떤 지표는 1에 가까울수록 좋아요.

📏 모델별 대표 지표 (카드를 눌러 뒤집어 보세요)

교과서 128쪽은 회귀분석을 「인과관계를 찾기 위한 방법」이라고 써요. 하지만 Ⅱ단원에서 배운 것처럼 두 값이 함께 변한다고 원인과 결과라고 단정할 수는 없어요. 이 화면에서는 회귀분석을 변수 사이의 관계를 찾고 값을 예측하는 방법이라고 써요.

🔍 오차를 눈으로 보기 (02의 연도별 사용량)

빨간 점선이 오차(실젯값 − 예측값)예요. 오차를 제곱해 평균 낸 값이 평균 제곱 오차(MSE)예요.

MSE –

02에서 사용량을 바꿨다면 그 값으로 계산돼요. 점들이 직선에 가까울수록 MSE가 작아져요.

04

(선택) 함께 해결하기 · 붓꽃 데이터로 두 도구 비교

교과서 129쪽 · Linear Regression · Data Sampler · Test and Score · scikit-learn

쉽게 말하면붓꽃(iris) 데이터에서 꽃잎 너비로 꽃받침 길이를 예측하는 선형 회귀 모델을 오렌지3와 파이썬으로 각각 만들어 보고, 두 도구를 비교해요. 시간이 남는 모둠이 해요.

🍊 오렌지3 흐름 (오렌지3에 들어 있는 데이터라 파일이 필요 없어요)

번호위젯 (카테고리)어디에 연결설정 · 할 일확인할 것
1Datasets (Data)처음 위젯목록에서 Iris를 골라 불러오기150개의 데이터
2Data Table (Data)Datasets →두 번 눌러 내용 확인열 이름: sepal length · sepal width · petal length · petal width · iris
3Select Columns (Transform)Datasets →Features에 petal width만, Target에 sepal length만 두고 나머지는 Ignored로교과서의 feature = petal_width, target = sepal_length
4Data Sampler (Transform)Select Columns →Fixed proportion of data 70%훈련용 105개, 나머지 45개
5Linear Regression (Model)(따로 둠)기본 설정 그대로Test and Score에 이어요
6Test and Score (Evaluate)Data Sampler 두 줄 + Linear Regression →Data Sample → Data, Remaining Data → Test Data로 잇고, 왼쪽에서 Test on test data 고르기MSE · RMSE · MAE · R2 값

Data Sampler와 Test and Score를 이을 때 뜨는 창에서 선을 두 개(Data Sample→Data, Remaining Data→Test Data) 만들어요.

🐍 파이썬 코드 (교과서 129쪽 코드를 줄여 옮김)

from sklearn.datasets import load_iris
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score

iris = load_iris()
X = iris.data[:, 3].reshape(-1, 1)   # petal_width (꽃잎 너비)
y = iris.data[:, 0]                  # sepal_length (꽃받침 길이)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size = 0.3, random_state = 42)

model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print('R2 :', r2_score(y_test, y_pred))
print('MSE:', mean_squared_error(y_test, y_pred))

코랩 새 노트북에 붙여 넣어 실행해요. 교과서 129쪽에는 R² 0.7383, MSE 0.1742로 나와 있어요. 오렌지3는 훈련용·테스트용을 무작위로 나누므로 값이 조금 다를 수 있어요.

마무리

핵심 문장 · 오늘의 질문 · 마무리 퀴즈 · 생각 정리 질문폼

「내일 아이스크림이 몇 개 팔릴까?」처럼 지난 판매 기록이라는 정답이 있고 알고 싶은 값이 개수라면 회귀분석을, 정답 없이 손님들을 비슷한 무리로 나누고 싶다면 군집 분석을 고른다. 문제와 데이터가 모델을 정한다.
연도별 사용량 다섯 개를 스프레드시트·오렌지3로는 눌러서, 파이썬·R로는 코드로 그려도 추세선은 똑같다. 도구는 목적과 익숙함, 다시 쓸 일까지 생각해 고른다.
모델을 만든 뒤에는 평가 지표로 확인한다. 예측 오차를 보는 MSE는 작을수록, 정확도와 실루엣 계수는 1에 가까울수록 좋고, 연관 규칙은 지지도·신뢰도·향상도로 따진다.
