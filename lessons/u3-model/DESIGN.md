**줄인 것**
- 122쪽 점검해 보기(용어 연결)·123쪽 생각 정리하기는 시작 화면 이야기와 칩으로 대신하고 옮기지 않았다.
- 127쪽 파이썬·R 코드는 그림을 그리는 핵심 줄만 남겨 탭 안에 옮겼다(쪽 표시). R은 패키지 설치 줄을 뺐다. 코드를 실행하는 실습은 두지 않고 「도구별 결과 비교」로만 쓴다(교과서 127쪽 말풍선 「코드를 이해하기보다 시각화 결과를 확인」).
- 128쪽 분류 분석의 의사결정나무 그림(타이타닉)은 넣지 않고 카드 글로만 설명했다.
- 129쪽 파이썬 코드에서 MAE·RMSE 줄은 빼고 R²·MSE만 출력하게 줄였다.

**확인할 점** (화면에서 바로잡음)
- **128쪽 「회귀분석은 독립 변수와 종속 변수 간의 인과관계를 찾기 위한 방법」**(설계안 확인할 점 1): Ⅱ단원(상관≠인과)과 어긋나 03 note에서 「변수 사이의 관계를 찾고 값을 예측하는 방법」으로 바로잡고 까닭을 적었다. 131쪽 「회귀분석은 여러 변수 사이의 관계를 쉽게 이해하고 결과를 예측하는 방법」과도 맞다.
- **126쪽 ows**: File → Data Table →(Selected Data) Scatter Plot. 오렌지3 3.40 Data Table의 기본 출력은 Selected Data라 줄을 고르면 고른 줄만 넘어간다. 흐름도는 File에서 Scatter Plot으로 바로 잇고, 교과서처럼 이었다면 줄을 고르지 말라고 note에 적었다.
- 126쪽 실습 데이터 CSV(교과서 자료실 `126쪽_오렌지_데이터.csv`)의 열 이름은 「연도」「사용량」, 127쪽 코드는 year·count. 화면 표·그림은 연도·사용량으로 맞췄다.
- 129쪽 「‘dataset’ 위젯」「‘datatable’ 위젯」 → 오렌지3 3.40 이름 **Datasets**, **Data Table**. 오렌지3 iris의 열 이름은 `petal width`·`sepal length`(밑줄 없음), 교과서는 petal_width·sepal_length(사이킷런 표기). 설정 표에 둘 다 적었다.
- 129쪽 Test and Score 연결: Data Sampler의 Data Sample → Data, Remaining Data → Test Data, 「Test on test data」를 골라야 70:30 평가가 된다(교과서는 연결 방법을 적지 않음). 설정 표에 적었다. 오렌지3는 무작위 표본이라 R²가 0.7383과 다를 수 있다고 note.
- 124쪽 「예 합격 여부 예측」은 분류의 예로 길잡이 그림에만 썼고, 퀴즈·sorter에서는 다른 상황(통과·미통과)을 썼다. 분류 모델은 교과서 128쪽 「분류 분석(정확도)」에서만 다루므로 sorter의 한 묶음으로만 둔다.

**지어낸 것(예시 표시)**
- 시작 칩의 데이터 목록(교과서 세 정보 + 지난주 판매량·시험·방학 일정·요일·근처 가게 할인).
- 01 sorter 8장(생수 판매, 중고 자전거 가격, 스팸 메일, 통과·미통과, 도서관 이용자, 음원 앱 사용자, 컵라면·삼각김밥, 함께 담기는 책).
- 퀴즈 상황(아파트 관리비, 헬스장 회원, 샴푸 → 린스, 걸음 수·수면 시간으로 기분 점수).
- 교과서에 인쇄된 값(126쪽 연도별 사용량 5개, 표 Ⅲ-1, 129쪽 R² 0.7383·MSE 0.1742)은 쪽 표시와 함께 씀. 연도별 사용량의 추세선 기울기 1.4, MSE 0.72는 `stat.fit`으로 계산(파이썬 statsmodels OLS와 같은 최소제곱 직선).
