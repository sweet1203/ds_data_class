퀴즈 11문항(정답 위치 ①4 ②3 ③4). 질문폼 1번 ← 02 실험·`missMemo`, 2번 ← 03 탐지기·73쪽 계산·`iqrCheck`·`iqrMemo`, 3번 ← 03 사례·`casePick`·`caseMemo`.
도구: 없음(70~73쪽은 개념 쪽, 오렌지3 실습은 u2-preprocess-lab). 사분위수는 교과서·pandas와 같은 선형 보간으로 계산하고 화면에 계산 방법을 한 줄로 적음(지도서 177쪽 describe 예시 25% = 32.5와 같은 방식).

**50분 흐름**
- 0~3분 시작: 수현이 이야기 → 수면 기록 「평균 내 보기」(17시간) → 처음 생각·나의 계획 메모
- 3~9분 01: 전처리 정의와 네 방법 → 분류 8장 → 퀴즈 2
- 9~20분 02: 결측치·표 Ⅱ-3·표기·제거와 대체·대표성·표 Ⅱ-4(4분) → 실험(소득이 낮은 3가구 → 세 방법 → 실제 공개 → 아무 3가구로 다시 뽑기, 5분) → `missMemo`(19분 무렵) → 퀴즈 3
- 20~35분 03: 이상치·사분위수 그림(3분) → 탐지기 미션(5분, 28분까지) → 73쪽 계산(3분) → `iqrMemo`(31분 무렵) → 처리 방법 카드(1분) → 사례 3장·`caseMemo`(35분 무렵) → 퀴즈 3. 추세선 실험은 접어 둠(선택).
- 35~45분 마무리: key3 → 오늘의 질문 → 퀴즈 3 → 질문폼. 5분 여유.
- 질문폼 1·2번 근거는 31분 안에 닿음. 3번 근거(사례 메모)는 35분 무렵이라 30분을 조금 넘음 → 시간이 모자라면 선생님이 03 첫 카드(이상치 뜻)를 짧게 넘기고 사례로 바로 가도록 안내.

**줄인 것**
- 표 Ⅱ-4는 연도 열과 std·25%·75% 줄을 빼고 해수면 높이 열의 행 수·count·mean·min·50%·max만 옮김(사분위수는 03에서 배우므로).
- 그림 Ⅱ-2의 산점도는 글로만 설명하고 박스 플롯만 다시 그림. 그림 Ⅱ-3(연도별 꺾은선)은 그리지 않고 값으로 계산하는 단계로 바꿈. 그림 Ⅱ-4는 교과서 예측값 두 개만 인용하고, 직접 해 보는 추세선 실험은 지어낸 값으로 (선택) 접기.
- 73쪽의 「변환」(이상치 처리 방법 중 하나)은 「대체가 어려울 때 정규화(다음 시간)」 카드로만 연결.
- 85쪽 「내 계획 점검하기(62, 70쪽)」는 u2-preprocess-lab 정리 화면에서 하도록 남김. 이 차시의 70쪽 계획 메모 키는 `plan`.

**확인할 점(교과서·지도서)**
- **73쪽 날개 「IQR: 4.57 − 0.125 = 4.450」** → 4.575 − 0.125(결과 4.450은 맞음). 하한값 −6.55·상한값 11.25, 72쪽 표 Ⅱ-4의 Q1 0.125·Q3 4.575와 서로 맞음(설계안 확인할 점 4). 화면 「73쪽 값으로 계산하기」 풀이에 바로잡는 문장을 넣음.
- **72쪽 표 Ⅱ-4 「대체」 열은 평균 대체**로 확인됨: 50% 값이 평균 3.085294와 같고, 표준편차 4.414505 = √(4.6108² × 33 ÷ 36)으로 평균 3개를 더한 결과와 맞음. 교과서 본문은 「특정 값으로 대체」라고만 써서, 화면 표 아래에 「결측치 3칸을 평균값으로 채운 결과」라고 밝힘.
- **71쪽 「평균값, 중앙값, 최빈값 등의 특정 값으로 결측치를 대체하여 데이터의 분포를 유지할 수 있다」**: 같은 값을 여러 칸에 채우면 값이 가운데로 몰려 분포가 좁아짐(표 Ⅱ-4에서도 표준편차 4.61 → 4.41, 25% 0.125 → 0.5). 화면 카드에는 「분포를 유지」를 빼고 「행을 지우지 않아 손실을 줄이고 왜곡을 줄이는 데 유용」으로만 씀. 선생님 확인 필요.
- **72쪽 그림 Ⅱ-2 박스 플롯**은 수염 끝에 「하한값」「상한값」을 붙여, 수염이 경계값까지 가는 것처럼 보임. 실제 박스 플롯(오렌지3·matplotlib)의 수염은 경계 안쪽에서 가장 먼 값까지 그림. 화면 그림과 탐지기는 경계값을 빨간 점선으로 따로 그리고 수염은 경계 안쪽 값까지 그림.
- 70쪽 수면 통계(7시간 32분, 미국수면재단 8시간 30분, 75.3%, 48.1%)는 출처가 적혀 있지 않음. 지도서 174쪽 동기 유발 자료(질병관리청 2023 청소년건강행태조사: 고등학생 5.9시간)와 다른 조사라 숫자가 다름. 화면에는 교과서 숫자만 「연구에 따르면」으로 씀.
- 73쪽 「이상치는 평균이나 분산과 같은 통곗값을 왜곡」의 「분산」은 94쪽에서 배우는 말이지만 교과서 문장이라 그대로 둠(퀴즈·해설에는 쓰지 않음).
- 73쪽 처리 방법은 「제거, 대체, 변환」뿐인데, 사례 활동에 「남겨 두고 살펴보기」 선택지를 넣음. 근거: 지도서 176~177쪽 지도상의 유의점(「이상치가 항상 제거 대상이 아니」, 「분석 목적에 맞는 유연한 처리」)과 교수·학습 자료(「제거가 필요하지 않은 경우」). 지도서의 예(체온 39.8℃, 금융 거래)는 옮기지 않고 새 사례를 씀.
- 71쪽 「결측치라고한다」 띄어쓰기는 화면에서 고쳐 씀.

**검토 반영(1차, 독립 검토 · 총괄 결정)**
- 03 순서를 「이상치 → 사분위수 → **탐지기(+`iqrMemo`)** → 처리 방법 → **이 이상치, 어떻게 할까?(+`caseMemo`)** → 73쪽 계산(`iqrCheck`)」으로 바꿈. `iqrMemo`를 탐지기 카드로 옮겨 질문폼 2·3번 근거가 30분 무렵에 닿게 함. 바뀐 흐름: 01 3~8분 → 02 8~19분(`missMemo` 18분 무렵) → 03 19분 시작, 탐지기 ~27분(`iqrMemo`), 처리 방법·사례 ~31분(`caseMemo`), 73쪽 계산 ~34분 → 마무리 35~45분.
- `missMemo` 질문 3개 → 2개(두 시나리오 비교 / 삭제해도 되는 때).
- 탐지기 미션 3: 고정 기준(평균 7.3, Q3 7.75) 대신 끌기(또는 키보드로 옮기기) 직전 값을 저장해 「끌기 전 → 16일 때」 평균·Q3를 실제 값으로 비교하고, Q3가 그대로인지에 따라 문구를 고름.
- 사분위수 안내: 「프로그램마다 계산 방법이 달라 값이 조금 다를 수 있어요(오렌지3 Box Plot은 가운데 두 값의 한가운데를 써요)」로 보강.
- 퀴즈 2-2 오답 「한 집단에만」 → 「한 집단에」(극단어 「만」). 1-1 해설을 사례 문장(설문 빈칸·잘못 적힌 나이)으로 바꿔 119쪽 빈칸 7번 정의 문장과 거리 둠. 1-2 문장을 「학생들의 도서 대출 데이터와, 그 학생들의 체력 검사 데이터를」로(지도서 178쪽 인적 사항·건강 검진 예와 다른 소재).
- 분류 카드: 「1반·2반 같은 설문지」 → 「작년·올해 축제 만족도 응답(같은 문항)」. 집계 카드 「달마다 합계로 묶는다」 → 「달마다의 합계 값으로 다시 계산한다」, 해설에 집계의 뜻과 축소가 아닌 까닭을 보탬.
- 사례 1(65시간) 해설: 「대체」를 교과서 73쪽 뜻(평균값·중앙값 같은 값으로 바꿈)에 맞추고, 본인 확인으로 바로잡는 것은 따로 적음.
- 「남겨 두고 살펴보기」 선택지, 71쪽 「분포를 유지」 처리는 총괄 결정대로 지금 그대로 둠.
