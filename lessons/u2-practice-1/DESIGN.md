## 검토 반영(1차)
- **Group by 범주형 Mode(심각)**: 오렌지3 3.40 Group by는 범주형 속성의 기본 집계가 Mode라 「- Mode」 열이 더 생김(owgroupby.py `DEFAULT_AGGREGATIONS`). 설정 표 7번에 「범주형 속성 줄의 Mode 체크를 풀어요」, 「확인할 것」에 「- Mode 열이 보이면 Mode 체크를 풀지 않은 것」, 8번 확인할 것을 「city와 - Mean 속성 8개」로, 흐름도 7번 상자·진행 체크에 「Mode 풀기」. 교과서 ows는 범주형 집계가 비어 있음(그림 106쪽도 Mean만) — 이 차이를 확인할 점으로 남김.
- **위젯 이름(총괄 결정)**: 「Column Statistics(교과서·옛 버전 이름은 Feature Statistics)」로 병기. 「3.40 이상에서는」 → 「최근 버전에서는」. 흐름도 ①·②의 3번 상자, 설정 표, 결과 읽기·막혔을 때 문장, 퀴즈 2-1·2-2, 질문폼 1번, 코랩 표, 고친 노트북 주석까지 맞춤.
- **50분**: 결과 읽기 9칸 → 6칸(숙박 인원 Min·Mode, 결측 속성 수 칸을 빼고 「Missing 열이 모두 0인지 눈으로」 한 줄). Box Plot ②(숙박 인원)는 설정 표에서 (선택)으로, 화면 상자 그림 접기를 「오렌지3에서 못 했을 때」로. 흐름: 시작 3 → 01 5(8분) → 02 10(18분) → 03 7(25분, 질문폼 3번 근거) → 04 13(38분) → 마무리 8.
