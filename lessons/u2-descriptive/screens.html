01

데이터 분석 방법에는 무엇이 있을까?

교과서 89쪽 · 탐색적 데이터 분석 · 기술 통계 · 상관분석

쉽게 말하면본격적으로 분석하기 전에 데이터를 그려 보고 요약해 보며 어떻게 생겼는지 탐색하는 단계가 있어요. 이때 속성 하나하나의 특징을 보면 기술 통계, 속성 두 개가 함께 변하는지를 보면 상관분석이에요.

🔍 탐색적 데이터 분석

데이터 분석의 초기 단계에서 데이터의 구조를 이해하고, 데이터가 가진 패턴과 이상치, 변수들 간의 관계 등을 이해하기 위해 수행되는 분석 방법. 데이터를 시각화하고 요약 통계를 사용해 패턴, 이상치, 변수들 간의 관계를 찾아내는 과정이에요.
📏

기술 통계 (descriptive statistics)

각 데이터 속성별 중심 경향과 분포를 통계적으로 살펴보는 방법이에요. 데이터 속성 자체의 특징을 파악하는 데 주안점을 둬요.

대푯값 · 평균, 중앙값, 최빈값 등산포도 · 사분위수 범위, 분산, 표준편차 등

🔗

상관분석 (correlation analysis)

데이터 속성 간의 상관관계를 파악해 어떤 속성들이 서로 연관되어 있는지 확인하는 방법이에요. 키가 큰 사람이 몸무게도 더 나가는 경향처럼요.

상관관계상관계수상관분석은 다음 시간에 배워요.

이러한 탐색적 데이터 분석은 주로 기계학습(컴퓨터가 데이터로 스스로 학습해 규칙을 찾고 새 데이터의 결과를 예측하는 것)이나 딥러닝(인공신경망으로 복잡한 패턴을 학습하는 기계학습의 한 분야) 모델을 적용하기 전에, 데이터의 특징을 파악해 모델의 방향을 정하려고 해요.

🧩 어느 분석일까?

무엇을 알아보려는지 읽고, 속성 하나의 특징을 보는지 두 속성 사이를 보는지 골라요.

02

데이터 전체를 하나의 값으로 나타낸다면?

교과서 90~91쪽 · 대푯값 · 평균 · 중앙값 · 최빈값 · 함께 해결하기

쉽게 말하면한 사람의 데이터만으로는 그 직업 전체의 스트레스를 말할 수 없어요. 여러 사람의 데이터를 하나의 값으로 나타낸 것이 대푯값이에요. 평균·중앙값·최빈값 중 무엇을 쓰느냐에 따라 분석 결과가 달라질 수 있어요.

중앙값 (median)

크기 순서로 나열했을 때 가장 가운데 값이에요. 개수가 짝수이면 가운데 두 값의 평균이에요. 극단으로 치우친 값의 영향을 적게 받아요.

🗳️

최빈값 (mode)

가장 자주 나타나는 값이에요. 숫자로 나타낼 수 없거나 구분하는 용도로 쓰는 범주형 데이터의 대푯값으로 써요.

힌트: 길동이보다 높은 사람이 5명 이상이어야 해요. 그런데 평균은 50점이어야 하니, 그만큼 나머지 몇 사람의 점수는 어떻게 되어야 할까요?

데이터는 얼마나 흩어져 있을까?

교과서 94~95쪽 · 산포도 · 분산 · 표준편차 · 사분위수 범위

쉽게 말하면평균이 같아도 데이터가 평균 가까이 모여 있는지, 멀리 흩어져 있는지는 다를 수 있어요. 데이터의 분포가 중심값에서 얼마나 흩어져 있는지 나타내는 값이 산포도예요.

²

분산

각 값과 평균의 차이(편차)를 제곱한 뒤 그 평균을 낸 값이에요. 0 또는 양의 값이고, 평균 가까이 모이면 0에 가깝고 멀리 흩어지면 커져요.

√

표준편차

분산은 편차를 제곱해서 값이 과장될 수 있어요. 그래서 분산의 제곱근을 구해 원래 단위로 되돌린 값이 표준편차예요.

📦

사분위수 범위 (IQR)

크기 순서로 나열해 네 부분으로 나눌 때 제3사분위수 − 제1사분위수예요. 중앙값을 기준으로 가운데 50% 데이터가 놓인 범위예요.

🧪 산포도 비교기 (두 반 10명씩, 예시 점수)

점을 좌우로 끌어 점수를 바꿀 수 있어요. 가는 선은 각 점수의 편차(평균과의 차이)예요. 분산은 교과서 정의대로 편차 제곱의 평균(÷ 10)으로 계산해요.

미션
  1. 처음 점수에서 두 반의 평균과 표준편차를 비교해요.
  2. B반에서 가장 낮은 점수(40점)를 왼쪽 끝까지 끌어 보세요. 표준편차와 사분위수 범위 중 무엇이 더 많이 변하나요?
  3. A반 점수를 끌어 A반의 표준편차를 B반보다 크게 만들어 보세요.

📦 A반과 B반의 수학 점수 (95쪽 박스 플롯을 다시 그림)

A반은 사분위수 범위가 25(60~85)로 좁고, B반은 40(55~95)으로 넓어요. 상자가 넓을수록 점수 차이가 크고 산포도도 커요. 수염 끝 위치는 교과서 그림을 보고 대략 그렸어요.

직업별 스트레스 수준을 분석해 보자

교과서 92~95쪽 · Group by · Select Rows · Bar Plot · (선택) Box Plot · Violin Plot

쉽게 말하면진영이의 궁금증을 데이터로 풀어 봐요. 지난 시간에 전처리한 Sleep_Health_merge.csv에서 데이터가 너무 적은 직업은 빼고, 직업별 스트레스 수준의 평균과 중앙값을 막대그래프로 비교해요(필수: 흐름도 1~8). 직업별 흩어진 정도는 아래 탐색기의 박스 플롯 탭으로 보고, 시간이 되면 오렌지3 Box Plot으로도 확인해요.
📌 표준화된 값 읽기 · 이 파일의 수면 시간·수면의 질·신체 활동 수준·스트레스 수준·걸음 수는 지난 시간(81쪽)에 표준화한 값이라 0.909, −0.786처럼 보여요. 1~10 점수로 읽지 말고, 0보다 크면 전체 평균보다 높고, 0보다 작으면 낮다고 읽어요. 막대그래프 세로축도 이 값이에요.
원래 점수로 바꾸면 얼마쯤일까? (펼쳐 보기)

표준화 전 스트레스 수준의 전체 평균은 약 5.4점, 표준편차는 약 1.8점이었어요. 그래서 0.909는 원래 점수로 약 7점, −0.786은 약 4점, −1.351은 약 3점이에요(원래 점수 ≈ 5.4 + 1.8 × 표준화 값).
