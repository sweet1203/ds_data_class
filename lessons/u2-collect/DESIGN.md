- **실험 안내 문구**: 「양쪽에 고르게 흩어져요」 → 「양쪽에 흩어지며 표의 『전체 평균과의 차이』가 작아요. 표의 차이 값을 세 방법끼리 비교해 보세요」. `biasWhy` 자리표시도 평균 차이·큰 횟수를 쓰게 고침. 퀴즈 3-2 정답을 「전체 평균 양쪽에 흩어지고 차이가 작다」로 맞추고 해설도 고침.
- **02 문구 단서**: 「데이터를 얻는 길은 크게 세 가지」 → 「이 화면에서는 데이터를 얻는 길을 세 가지로 나눠 봐요」. 묶음 이름 「공개된 데이터 받기」 → 「기관·기업이 공개한 데이터」, 카드 7·8의 「받아·받았다」 → 「파일로 분석했다」「파일을 분석에 썼다」.
- **04 ① 수집 방법 결과**를 확인 요약 문장(「① 수집 방법은 맞게 골랐어요 / 다시 볼 곳이 있어요」)과 `checkLog`(① 고른 방법·다시 볼 것, ② 맞힌 수)에 넣음.
