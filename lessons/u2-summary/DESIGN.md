**줄인 것**
- 68쪽 「파이썬으로 해 보기」는 03의 `details` 선택 활동(사본 만들기·파일 올리기·코드·describe 읽는 표)으로. 고친 노트북은 저장소 밖 `작업자료_데이터과학/노트북_2단원/68_비만 데이터 요약 통계.ipynb`.
- 67·68쪽 오렌지3 화면 캡처는 넣지 않고, 흐름도(SVG)와 설정 표, Feature Statistics 표를 HTML로 다시 그림. 분포 막대는 원 파일의 구간별 개수(집계값)로 모양만 그림.
- 69쪽 함께 해결하기의 「예」 문장(모기 물림 문제·기후 가설·수집 방법)과 예시 통계값(37.74 등)은 옮기지 않음. 문제 예는 「점심시간 매점 줄」로 바꿈. 특성 분석 표는 속성 2줄(교과서는 4줄)로 줄이고, 분포 칸은 그림 대신 「모양을 말로」.
- 69쪽 성취도 평가는 칩 4개로. 「주요 개념 정리하기」는 쓰지 않음.

**확인할 점**
- **68·69쪽 「분산(Disperision)」**(설계안 확인할 점 1): 오렌지3 Feature Statistics의 Dispersion은 표준편차(n으로 나눔) ÷ 평균이다. 나이 0.23857 = 5.6879 ÷ 23.8418(이 맥의 오렌지3 3.40으로 다시 계산해 같음). 실제 분산은 약 32.35. 69쪽 모기 0.75도 같은 식. 화면은 「흩어진 정도(Dispersion)」로 쓰고, 「표준편차를 평균으로 나눈 값이라 분산과 달라요」 한 줄을 02에 접어 둠. 「Disperision」은 철자 오타 → 화면은 Dispersion. 계산기의 흩어진 정도 값도 같은 식(n으로 나눈 표준편차 ÷ 평균)으로 계산.
- **68쪽 「중앙값이 평균보다 낮아 데이터가 왼쪽으로 치우쳐」**(설계안 확인할 점 2): 지도서 173쪽(69쪽 예시)은 같은 상황을 「오른쪽으로 치우친」으로 써서 반대. 화면·퀴즈·메모 안내에는 방향 낱말을 쓰지 않고 「젊은 쪽에 많이 몰리고 나이 많은 몇 명이 평균을 끌어올림」으로 씀. 68쪽 「분산은 0.24로 매우 낮아 … 평균 가까이 집중」은 「흩어진 정도」로 바꿔 읽으면 뜻이 통해 화면에서 따로 다루지 않음.
- **67쪽 범주형 속성 수**(설계안 확인할 점 3): 본문은 성별·가족력 과체중 여부·비만도 등급 3개만 범주형이라 했지만, 오렌지3는 FAVC(0·1)도 categorical로 읽는다(67쪽 File 창 그림과 이 맥의 오렌지3 3.40으로 확인). 01 체험의 정답은 오렌지3가 읽은 형(범주형 4개)으로 하고, FAVC 해설에 「교과서 본문은 세 속성만 들었지만」을 밝힘.
  - 「0BE1DAD」는 원래 열 이름 NObeyesdad가 깨진 것(파일 값 `0rmal_Weight`도 Normal_Weight가 깨진 것). 화면에는 「0be1dad · 비만도 등급」으로 쓰고 해설에 원래 이름을 밝힘.
- **67쪽 id**: 교과서는 수치형에 넣고 오렌지3도 numeric으로 읽지만, 아이디는 사람을 구별하는 번호라 Ⅰ단원(이름·대여 번호를 범주형으로 본 것)과 어긋날 수 있음 → 두 답 인정(노란 줄), 「분석할 때는 빼고 봐요」.
- **68쪽 통계 창(Feature Statistics) 화면의 Mode 열**: 교과서 용어 목록에 없음(최빈값은 90쪽). 화면에 「Mode는 최빈값, 기술 통계 시간에 배워요」 한 줄.
- **69쪽 모기 데이터의 속성 수**: `date` 열을 오렌지3는 datetime으로 읽어 수치형·범주형 어느 쪽에도 들지 않음(File 창 「13 features」에는 들어감). 표의 수치형·범주형 칸을 채울 때 헷갈릴 수 있어 「막혔을 때」 접기에 안내함(지도서 173쪽 예시 답은 옮기지 않음).
- 69쪽 「서울 열린 데이터 광장」과 63쪽 「서울 열린데이터 광장」의 띄어쓰기가 다름 → 63쪽 표기로 통일.
- **68쪽 나이 중앙값 「22.81」**: 실제 값은 22.815416이라 반올림하면 22.82다(교과서는 버림한 값으로 보임). 화면·퀴즈는 오렌지3 화면 값 그대로 22.8154로 써서 어긋나지 않게 함.
- 68쪽 describe의 `std`(n−1로 나눔)와 오렌지3 Dispersion 계산(n으로 나눔)이 달라, 코랩과 오렌지3 값을 비교하면 헷갈릴 수 있음 → 고친 노트북의 선생님용 메모에 적음. 화면 describe 표는 std·25%·75%를 「다음 시간들에 배워요」로만.
- **실습 파일 라이선스**: `obesity_level.csv`는 캐글 대회(Playground S4E2) 합성 데이터로 보여 이용 규칙 확인 필요, `Mosquito Activity Index.csv`는 서울시 자료 가공본(공공누리 유형 확인 필요) → 저장소에 넣지 않고 선생님 폴더로(설계안 데이터 파일 처리).
