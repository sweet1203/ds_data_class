질문폼(data-u4-review): 1번 ← 01 `summary`(~11분), 2번 ← 02 점검실 + `claim`(~23분), 3번 ← 03 `next`(~28분).

**선택 프로젝트 처리**
- 다른 차시 메모(`memoOf`)를 읽지 않는다. 모든 요약은 이 화면에서 새로 쓴다.
- 시작 vote에서 【선택】 두 프로젝트는 「우리 반이 한 경우만」이라고 적고, 하지 않았다면 스트레스 지수 예측이나 모둠 프로젝트를 고르게 했다. 메모 · 질문폼 · 퀴즈 어디에도 선택 프로젝트의 완료를 전제하지 않는다(퀴즈에 영화 · 국가 데이터 내용 없음. 5-1 군집 번호 문항은 Ⅲ단원 군집 분석으로 풀 수 있음).
- 모둠 프로젝트는 실제 수행을 끝내지 않았을 수 있어, 떠올릴 거리에 「아직 하지 않은 단계는 계획으로 적어도 된다」고 적었다.

**50분 흐름**
- 시작(2분) 프로젝트 고르기
- **01(9분, ~11분)** 프로젝트 표 1분 → 급식 대기 sorter 3분 → `summary` 4분(질문폼 1번 근거) → 퀴즈 1분
- **02(12분, ~23분)** 판단 기준 1분 → 주장 8개 판단 5분 → 확인 · 설명 읽기 2분 → `claim` 3분(질문폼 2번 근거) → 퀴즈 1분
- **03(11분, ~34분)** 발표 틀 1분 → `next` 4분(~28분, 질문폼 3번 근거) → 짝 발표 · 질문 5분 → 퀴즈 1분
- **04(6분, ~40분)** 개발자 카드 2분 → 칩 · `career` 3분 → 퀴즈 1분
- 마무리(10분) key3 · 오늘의 질문 · 마무리 퀴즈 · 질문폼

**줄인 것**
- 227쪽 단원 정리(세 프로젝트를 여섯 칸에 정리하는 문항)는 문장 · 빈칸 구성을 옮기지 않고, 학생이 고른 프로젝트 하나를 메모로 요약하게 바꿈. 지도서 예시 답안(결측치 · 이상치 개수, MSE · R² 값, RMSE 값, k-means 3그룹 등)은 쓰지 않음.
- 227쪽 「역량 Check!」 체크 목록은 옮기지 않고, 이 단원에서 해 본 일 칩(새로 쓴 낱말)으로 대신함.
- 226쪽 대화문은 인용하지 않고 하는 일 · 경험 · 역량 세 카드로 줄여 씀. 개발자 이름은 싣지 않음. 개인정보 보호 강조는 지도서 226쪽 지도 Tip을 바탕으로 함.

**확인할 점**
- 227쪽 스트레스 · 영화 · 국가 프로젝트의 학습 결과값은 앞 차시마다 달라질 수 있어(Ⅳ단원 설계안: 교과서 결과값을 정답으로 강제하지 않음) 화면에 수치를 적지 않음.
- 점검실 2번(학습 데이터 R² 0.95 → 95% 맞힘)과 5번(군집 번호 → 지원 순서)은 설계안 「확인 · 수정할 설명」의 R² 해석 · 군집 번호 항목을 새 예시로 반영함.

**지어낸 것(예시 표시)**
- 01 급식 대기 줄 프로젝트(sorter 6장), 프로젝트별 떠올릴 거리.
- 02 점검실 주장 8개(독서 기록 · 급식 대기 줄 ×2 · 수면 설문 · 지역 군집 · 출석 확인 · 동아리 신청 · 추천 대상 선정)와 수치(상관계수 0.6, R² 0.95, 25명 등). 화면에 「이 화면을 위해 만든 예시」라고 밝힘. 정답 분포: 근거에 맞는 주장 2 · 상관을 원인으로 단정 1 · 평가·해석이 지나침 2 · 대상을 넘어 일반화 1 · 개인정보·공정성 문제 2.
