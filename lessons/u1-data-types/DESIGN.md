퀴즈 12문항(정답 위치 ①4 ②4 ③4). 질문폼 1번 ← 01 투표·02 직접 구조화하기, 2번 ← 04 네 가지 데이터 구분·`whyType`, 3번 ← 03 `myData`·`myCols`.

**50분 흐름(검토 반영 후)** — 도입(3분) 원유 비유, 나의 계획 → 01(6분, 9분까지) 정의, 투표, 처음 생각 → **02(11분, 20분까지)** 표 Ⅰ-5 채우기·확인·닭고기 날 세기, 반정형은 훑기 → 03(5분, 25분까지) 버튼 세 개(찾기·합계·CSV) 눌러 보기, 내 데이터 메모 → **04(25분 무렵 시작)** 네 가지 구분 + 짝에게 이유 말하기, `whyType` 메모까지 30분 안 → 성취도 → 마무리(8분) 퀴즈·질문폼. 「한 걸음 더」·「개념 정리하기」는 (선택) 접기. 질문폼 근거 활동(02·03·04 첫 카드)은 모두 30분 안.

**줄인 것** — 22쪽 그림(데이터 대방출 일러스트)·23쪽 만화는 넣지 않고 대화 두 줄과 SVG 급식판으로. 그림 Ⅰ-2 사진 세 장은 글 카드 세 장으로. 25쪽 네 자료는 HTML로 다시 그림(댓글 글 내용은 새로 쓴 예시, 손 글씨는 글꼴로 흉내). 「한 걸음 더」 분류 게임은 교과서에 없는 연습(선택적으로 빠르게).

**확인할 점**
- **표 Ⅰ-5의 0/1 값**: 작업 요청에는 「교과서에 비어 있다」고 했지만, 받은 교과서 PDF 24쪽(PDF 15쪽)에는 값이 채워져 있다(25-03-04 돼지 1, 03-05 닭 1, 03-06 돼지 1, 03-07·08·11 닭 1, 나머지 0). 화면에서는 처음에 모두 0으로 두고 학생이 채우게 했고, 채점 기준은 이 교과서 값과 같다(메뉴 이름에 고기가 드러난 칸만 1). 학생용 교과서가 다른 판이라면 알려 주세요.
- **판단이 갈리는 칸(채점하지 않고 노란색으로 설명)**: 03-05 쇠고기·돼지고기(마라탕 — 고기를 넣기도 하나 종류가 이름에 없음), 03-07 쇠고기·돼지고기(소떡소떡 — 「소」는 소시지, 소시지 고기 종류는 알 수 없음), 03-11 돼지고기(김치만두 — 만두소에 돼지고기가 흔하나 이름에 없음). 교과서는 이 칸을 모두 0으로 적었다. 돈마호크(03-06)는 「돈(豚)」으로 돼지고기가 분명하다고 보고 채점, 치킨마요덮밥은 「치킨」으로 닭고기 채점. 해물 순두부찌개·게맛살·어묵·멸치는 네 열(쇠·돼지·닭·오리)에 해당하지 않아 0.
- **이메일**: 24쪽 본문은 이메일을 비정형 데이터의 예로, 같은 쪽 옆 설명은 반정형 데이터의 예로 든다. 화면 02 반정형 카드에 「본문은 자유 형식, 보낸 사람·시각은 구조 정보라 양쪽 예로 나온다」고 풀어 쓰고, 분류 게임·퀴즈에서는 이메일을 쓰지 않음.
- **센서 데이터**: 그림 Ⅰ-2는 센서 데이터를 비정형의 예로 든다(건강 앱 화면 사진). 일반적인 센서 측정값 기록(시각·값)은 정형에 가까워 헷갈릴 수 있어, 카드 설명을 「신호를 그래프로 보여 주는 건강 앱 화면」으로 적고 분류 게임에는 센서 항목을 넣지 않음(교실 온도 기록표는 「날짜·시각·온도 칸에 적은 기록표」로 정형).
- **25쪽 「제주도 해수면 데이터」**: 보이는 열이 측정 일자·정점명·정점 코드·위도·경도·평균 풍속·평균 기압으로, 해수면 높이 열은 없다(해양 관측 자료의 일부로 보임). 화면에는 교과서 이름 그대로 두었다.
- 23쪽 「천제의 움직임」 → 화면에는 「천체」(설계안 확인할 점 5).
- 23쪽 측주 사진 속 날짜는 check.py 날짜 규칙에 걸려 넣지 않음(메뉴 글만 사용).

**지어낸 것(예시 표시)** — 02 반정형 JSON(「(예시)」 표시, 값은 표 Ⅰ-4에서), 04 댓글 두 줄(「글 내용은 예시」 표시), 04 「한 걸음 더」 8장(「모두 새로 만든 예시」 표시), 03 메모 자리표시(휴대폰 사진첩·운동), 개념 빈칸 세 문장(체육 대회 사진·줄넘기 기록·JSON). 교과서 표 값(표 Ⅰ-4·Ⅰ-5, 25쪽 기대 수명·해수면 값)은 쪽 표시와 함께 그대로 씀.

**검토 반영(1차, 독립 검토)**
- 분량: 04 「한 걸음 더」 분류 게임과 「개념 정리하기」를 `details`로 접고 (선택) 표시. 03 버튼 체험에서 「날짜를 거꾸로 정렬」을 빼 네 개로(찾기 · 합계 · CSV · 원래대로). 50분 흐름을 위처럼 고쳐 04 `whyType`가 30분 안에 오게 함.
- 퀴즈 2-2 줄기에서 날짜(25-03-06)를 빼 「어느 날의」로(체험 답 노출 방지).
- 퀴즈 4-1·5-1·5-2가 같은 보기 세트(정형/반정형/비정형) → 5-2를 「스프레드시트·CSV 파일 데이터에 대한 설명」으로 바꾸고 새 보기(사진처럼 규칙이 없다 / 대부분 정형 데이터이다 / 속성을 뽑아야 표가 된다). 정답 위치 균형을 위해 4-2 정답을 가장 짧은 보기(「명확한 구조가 있는가」)로 다시 씀. 분포 ①4 ②4 ③4 유지.
- 03 메모 `myData`·`myCols` 예시가 질문폼 3번의 완성 답이 되던 것 → `myData`는 데이터 종류 예만(사진첩·대화방 글·음성 메모), `myCols`는 형식 안내(「열 이름을 | 로 나누어」)만.
- 분류 게임: 비정형 카드 두 장에도 가운뎃점 나열을 넣어(응원·결승전·시상식 영상, 급식·체육복·축제 건의 글) 「나열 = 정형」 단서를 없앰.
- 「확인하기」를 다시 누르면 `mealResult`의 「닭고기가 나온 날」이 사라지던 문제 → 날짜 수를 따로 기억해 다시 확인해도 함께 저장(처음부터 다시 누르면 지움).
- 표 Ⅰ-4 「돈육 고추장볶음」으로 PDF 표기 맞춤. 시작 화면 「영국 잡지」 덧붙임 뺌.
- 학생 화면 문구의 「채점」을 「확인한 ○칸 중」, 「맞고 틀림을 따지지 않았어요」로 바꿈.

**검토 반영(2차)**
- 마무리 key3 셋째 문장이 29쪽 주요 개념 정리하기 ➊과 거의 같던 것 → 표 Ⅰ-5 사례 문장(찾기·더하기·CSV 저장이 쉬워 사진 365장을 넘겨 보지 않고 닭고기 날을 셈)으로 바꿈.
- 퀴즈 2-1·3-1·4-2 정답만 가장 짧던 보기 → 세 보기 길이를 비슷하게 맞춤(정답 위치 그대로, 분포 ①4 ②4 ③4). 4-2는 「정리된 명확한 구조가 있는가 / 숫자가 하나라도 들어 있는가 / 데이터의 양이 수천 개 넘는가」.
- 03 「표 Ⅰ-5로 직접 해 보기」가 02 체험의 답을 그대로 보여 주던 것 → 02에서 「확인하기」를 누르기 전(`mealResult` 메모가 없을 때)에는 표를 숨기고 「02를 먼저 해요」 안내와 02로 가는 버튼을 보임. 03 화면에 들어올 때마다(onShow[3]) 다시 확인.
