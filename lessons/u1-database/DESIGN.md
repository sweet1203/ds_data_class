퀴즈 12문항(정답 위치 ①4 ②4 ③4). 질문폼(data-u1-database) 1번 ← 01 21세기 다산·`dasanNote`, 2번 ← 02 투표·sorter와 03 DBMS 설명, 3번 ← 03 ATM 실험·`atmNote`.

**50분 흐름** — 시작(4분) 임진왜란 토론 읽고 `whyDiff` 한두 줄 → 33쪽 정리 열기(`planDasan`은 선택) → 01(12분) 다산 흐름도·데이터셋 정의·표 Ⅰ-10 짧게, **21세기 다산 되기**(6분 안팎, 14줄 중 몇 줄을 직접 넣고 나머지는 「한 번에 넣기」 가능), `dasanNote` → 02(7분, 23분 무렵 끝) 정의·표 Ⅰ-11, 분류 게임, 은행 투표·`bankNote` → **03(23분 무렵 시작, 11분)** DBMS 그림·역할만 읽고(표 Ⅰ-12는 접힘) ATM 실험(26분 무렵 닿음, 「먼저 이 네 가지부터」 안내대로 6분) 기록표·`atmNote`(32분 무렵 끝), 접힌 「종류」 카드는 시간이 있으면 → 마무리(10분) 퀴즈·질문폼. 질문폼 근거 활동 1·2번은 23분 안, 3번(ATM)은 26분 무렵 닿음.

**줄인 것** — 32쪽 「점검해 보기」(진단 문항과 정답)는 넣지 않음. 32쪽 중단원 핵심 질문의 A 답은 마무리에서 학생이 직접 답하도록 싣지 않음. 33쪽 「역량 키우기 52쪽 안내」는 생략(07 차시 담당). 37쪽 LINK 89쪽 기계학습은 생략. 그림 Ⅰ-6 아이콘 그림은 이모지 목록으로, 그림 Ⅰ-7은 카드 3장으로. 36쪽 성취도 평가 체크는 화면에 넣지 않고 마무리 퀴즈 4-2(공통된 특성으로 모으기)로 대신함. 표 Ⅰ-11·Ⅰ-12는 교과서 표 그대로(정의형 표라 바꿔 쓰지 않음).

**확인할 점**
- 35쪽 그림 Ⅰ-4·Ⅰ-5의 연도 「1412년」은 34쪽 이야기(1789년 정조, 지도서 124쪽 「7년간(1789~1795)」)와 맞지 않음. 화면에서는 연도를 빼고 「03-05 · A 고을 …」, 「[A 고을 1년 차 식수 현황]」으로 씀.
- 35쪽 그림 Ⅰ-4·Ⅰ-5 데이터셋1의 1월 줄이 「소나무 10 · 잣나무 10 · 합계 30」으로 합계가 맞지 않음(합계 줄 100·100·200은 두 종류만 더한 값). 화면에서는 1월 합계를 **20**으로 고침.
- 36쪽 실습 데이터(xlsx)는 수원·광주 시트에 소나무·잣나무·단풍나무·뽕나무 4종이 날짜별로 있고, 집계 시트는 SUMPRODUCT 배열 수식. 화면 체험은 시트 값만 옮기고 함수는 쓰지 않음(「스프레드시트에서는 함수로 한 번에 집계할 수도 있어요」 한 줄만). 계산 결과는 교과서 36쪽 표(2019 13·9, 2020 10·13, 2021 14·5, 2022 6·17)와 같음. 날짜는 「○월 ○일」 대신 2019-04-05 꼴로 표기.
- 39쪽 ATM 실험의 「동시 요청」에서 트랜잭션 쪽이 기다렸다가 처리되는 모습은 교과서 본문에는 없고, 지도서 128쪽 교수·학습 자료(「트랜잭션이 진행되는 동안에는 다른 작업이 같은 계좌를 수정할 수 없으며」)를 근거로 함. 「동시 요청」 상황(어머니가 같은 계좌로 인출, 잔액 10만 원)도 지도서 128쪽 사례를 따름.
- 「비밀번호 입력 때 기록」은 금액을 먼저 요청한 뒤 비밀번호를 넣는 흐름으로 가정(화면 단계: 인출 요청 70,000원 → 비밀번호 입력 → 인출 승인 → 현금 지급).
- 정전은 「현금 지급 직전」 한 시점으로만 일으킴. 그래서 「현금 지급 뒤 기록」은 정전에는 ✅, 동시 요청에는 ⚠️가 나와 교과서의 두 위험(늦게 기록 → 추가 인출, 일찍 기록 → 정전 오류)이 기록표에 하나씩 드러남.

**지어낸 것(예시 표시)**
- ATM 금액(잔액 100,000원, 인출 70,000원)은 지도서 사례(10만 원)를 바탕으로 정한 예시 — 화면에 「(금액은 예시)」.
- 02 분류 게임의 상황 문장 6개(고양이 사진 CSV, 체육 측정 결과, 기온 그래프, 쇼핑몰, 학교 출결·성적, 병원)는 새로 지은 예.

## 검토 반영(1차)
- **30분 규칙**: 03에서 ATM 실험 카드를 「종류」 카드 앞으로 올리고, 「종류」(그림 Ⅰ-7·낱말 풀이)는 접힌 카드, 표 Ⅰ-12는 `details`로 접음. 시작 화면 「나의 계획」(`planDasan`)에 (선택) 표시. 이에 따라 「종류」에서 내던 퀴즈 3-3(RDBMS)을 ATM 문항(현금 지급 뒤 기록 + 동시 요청 → 추가 인출)으로 바꿈.
- **ATM 실험**: 「먼저 이 네 가지부터: ①·② × 정전 → ③ × 동시 요청 → ④ × 정전·동시 요청」 안내 한 줄. ③ × 정전 결과 문구에 「늦게 기록해도 동시 요청에는 위험해요」를 굵게 넣고 ③ × 동시 요청을 해 보게 함.
- **질문폼 2번 근거**: 02 투표 아래 한 줄 메모 `bankNote`(스프레드시트 한 장으로 하면 생길 문제)를 두고 MEMOLIST에 넣음. 문항은 그대로.
- **01 흐름도**: 「교과서 그림의 연도(1412년)와 데이터셋1의 1월 합계(30)는 바로잡아 실었어요」 한 줄.
- **아직 안 배운 말**: 표 Ⅰ-10 설명(`bookCap`)과 퀴즈 1-3 해설의 「칼럼」 → 「정해진 항목(필드)」.
- **퀴즈**: 2-1 오답 「DBMS」(03에서 처음 배움) → 「데이터」. 4-3 정답만 길던 것을 오답 「정형 데이터셋 파일」·「스프레드시트 프로그램」으로 길이를 맞춤.
- 36쪽 실습 파일 값 14줄을 화면 표로 쓰는 것은 총괄 확인(출처 쪽 표시 유지).
- 점검: build·check 오류 0·주의 0, node 문법 확인.

## 검토 반영(2차)
- 02 `bankNote` 안내문의 「DBMS」(03보다 먼저 나온 약어) → 「데이터베이스 관리 시스템」으로 풀어 씀.
- 퀴즈 4-3(MySQL 등)이 접힌 표 Ⅰ-12·종류 카드만 근거로 삼던 문제: 03 역할 카드 아래에 「데이터베이스 관리 시스템의 예: MySQL, PostgreSQL, Oracle, MongoDB 등(표 Ⅰ-12)」 한 줄을 펼쳐 두고, 해설도 그에 맞춤.
- 마무리 안내를 (선택) 메모를 전제하지 않게 「처음 생각(황윤길·김성일 메모)이나 나의 계획을 적었다면」으로 바꿈. 오늘의 질문 문장을 시작·마무리에서 같게(「…어디에, 어떻게 저장되는 것일까?」).
- ATM 안내 「먼저 이 네 가지부터」 → 「먼저 이 순서부터」. 퀴즈 2-2 오답의 「만」을 뺌. 퀴즈 3-2 오답 「스키마」(접힌 낱말 풀이에만 나옴) → 「무결성」.
- 점검: build·check 오류 0·주의 0, node 문법 확인.
