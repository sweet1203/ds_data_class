퀴즈 11문항(정답 위치 ①4 ②4 ③3).

질문폼(data-u3-regression): 1·2번 ← 01 직선 맞추기·`fitLog`·`fitW`(~17분), 3번 ← 03 sorter·`choose`(~30분).

**50분 흐름**
- 시작(3분) 영화 이야기·요소 칩·나의 계획
- **01(14분, ~17분)** 표 Ⅲ-2·모델 카드 4분 → 직선 맞추기 A 4분 → 데이터 B 2분 → `fitW` 2분 → 퀴즈 2분
- 02(5분, ~22분) 카드 6장 뒤집기 3분 → 퀴즈 2분
- **03(9분, ~31분)** 대화·표 Ⅲ-3 3분 → sorter 8장 3분 → `choose` 2분 → 퀴즈 1분 (질문폼 근거 여기까지)
- 마무리(12분) 오늘의 질문·퀴즈·질문폼. 남는 시간은 다음 차시(통계적 회귀 실습) 준비.

**줄인 것**
- 132쪽 핼리의 브레슬라우 출생·생존자 표, 대한민국·OECD 기대수명 그래프, 당뇨병 예측 모델 그림은 넣지 않고 카드 글로만 설명했다.
- 133쪽 두 친구 대화는 편마다 한 덩어리로 줄여 썼고, 대화 속 예(미세먼지·금융 사기·자율주행)는 sorter·퀴즈에 쓰지 않았다.
- 131쪽 디지털 샘의 Tip(지수·로그 회귀식)은 이름만 소개했다.

**확인할 점**
- 131쪽 「선형 회귀 … 독립 변수의 차수에 따라 1차 함수이면 선형, 2차 이상의 곡선이면 비선형」: 엄밀히는 2차 다항 회귀도 계수에 대해서는 선형 모델로 보기도 하지만, 교과서 분류(2차 다항 회귀 = 비선형)를 그대로 따랐다.
- 131쪽 「회귀분석 … 원인(독립 변수)」: 표 Ⅲ-2 설명의 「결과에 영향을 주는 원인」 표현을 그대로 썼다. u3-model 03에서 「회귀분석 = 인과관계」를 바로잡았으므로, 이 화면에서는 「원인」을 「영향을 주는 변수」의 뜻으로만 쓰고 인과를 강조하지 않았다.
- 오차: 교과서 128쪽 「오차(실젯값 − 예측값)」 용어를 썼다(잔차라는 낱말은 쓰지 않음). 「가장 잘 맞는 직선」은 MSE가 가장 작은 직선으로 설명하고 최소제곱법이라는 용어는 다음 차시(134쪽~)로 미뤘다.
- 퀴즈·key3에 R²(결정 계수)는 쓰지 않았다(134~139쪽 실습 차시에서 다룸).

**지어낸 것(예시 표시)**
- 01 데이터 A(공부 시간–시험 점수 12점), 데이터 B(하루 수면 시간–집중도 점수 13점, 산 모양). 화면에 「예시」 표시. 계산: A 가장 잘 맞는 직선 y = 5.29x + 46.5, MSE 5.4 / B y = 3.10x + 42.8, MSE 170.2. 슬라이더(w 0.5 간격, b 1 간격)로 A의 MSE 5.87까지 갈 수 있어 미션 「1.2배 안(≤6.48)」을 이룰 수 있다.
- 시작 칩(교과서 요소 6개 + SNS 입소문·상영 시간).
- 03 sorter 8장(공원 면적·운동 시간, 급식 잔반 원인, 비료·수확량 가설, 정류장·상가 매출 / 배달 도착 시각, 사진·후기로 판매량, 내일 전력 사용량, 새 노래 재생 횟수).
- 퀴즈 상황(운동 시간·식사량 → 체중 변화, 도서관 대여 기간·권수), key3 위성 사진·쌀 수확량.
- 표 Ⅲ-2 두 줄(교과서 131쪽)은 쪽 표시와 함께 씀.

**검토 반영(1차)**
- 퀴즈 1-1 줄기의 「예측」 → 「알아보려」, 4-3 줄기에서 「관계를 설명」을 빼고 해설은 목적(까닭을 보여 주기)·해석 필요만 근거로 함(「데이터 양」 근거 삭제).
- 03 sorter: 끝말(설명하려/맞히려)과 「수백만 건·영상·실시간」만으로 분류되지 않게 4장을 고침(공원: 예측값과 근거, 정류장: 예측하되 요인을 보여 줌, 배달: 대용량·영상 빼고 오차가 중요, 전력: 센서·실시간 빼고 기온·요일 기록).
- 메모 `choose`에 「새 상황도 하나 만들어」를 넣고, 질문폼 3번은 「헷갈렸던 상황이나 메모에 새로 만든 상황」으로 맞춤.
- 01 「결과에 영향을 주는 원인」 → 「결과에 영향을 줄 것 같은 변수」.
- 미션 aBest: 데이터 A에서 「가장 잘 맞는 직선 보기」를 누르면 「다시 하기」 전까지 인정하지 않음(`rgPeek`, 데이터 전환으로는 풀리지 않음). 안내 문구 추가.
