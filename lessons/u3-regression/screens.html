01

회귀분석이란 무엇일까?

교과서 131쪽 · 종속 변수 · 독립 변수 · 표 Ⅲ-2 · 선형 회귀 · 비선형 회귀 · y = wx + b

쉽게 말하면회귀분석은 여러 변수 사이의 관계를 수식으로 나타내어, 알고 있는 값으로 결과를 예측하는 방법이에요. 관계가 직선 모양이면 선형 회귀, 곡선 모양이면 비선형 회귀 모델을 써요.

🎯 예측하고 싶은 결과와 영향을 줄 것 같은 변수

학생의 시험 점수를 예측한다면 공부 시간, 수면 시간, 게임 시간이 점수에 영향을 줄 수 있어요.

📐 회귀분석에 쓰는 모델

선형 회귀 모델

독립 변수와 종속 변수의 관계가 직선 형태일 때 알맞아요. 독립 변수가 종속 변수에 주는 영향을 계수(w)로 추정해, 데이터에 가장 잘 맞는 직선 방정식을 구해 예측해요.

단순 선형 회귀(독립 변수 1개) y = wx + b
다중 선형 회귀(2개 이상) y = w₁x₁ + w₂x₂ + w₃x₃ + b

w는 각 독립 변수가 종속 변수에 미치는 영향력(계수), b는 절편

비선형 회귀 모델

관계가 곡선 형태일 때 써요. 선형 회귀로 설명할 수 없는 복잡한 패턴을 곡선이나 여러 수학 함수로 나타내요.

앙상블 모델 여러 예측 모델을 결합(예: 의사결정트리 여럿을 조합한 랜덤 포레스트)
신경망 사람의 뇌 신경 구조를 흉내 낸 알고리즘
그 밖에 2차 다항 회귀, 지수 회귀, 로그 회귀 등

📈 직선 맞추기 (점의 값은 연습용 예시예요)

슬라이더로 기울기 w와 절편 b를 움직여 점들에 가장 잘 맞는 직선을 찾아요. 빨간 점선은 점마다의 오차(실젯값 − 예측값)이고, 오차를 제곱해 평균 낸 MSE가 작을수록 잘 맞아요.

    02

    통계학과 기계학습

    교과서 132쪽 · 통계학의 역사적 사례 · 기계학습의 활용 사례

    쉽게 말하면통계학과 기계학습은 둘 다 데이터에서 정보를 뽑아 예측 모델을 만든다는 같은 목표를 가져요. 통계학은 인구 조사에서 시작해 오랫동안 쓰였고, 기계학습은 텍스트·이미지·영상·센서 데이터가 폭발적으로 늘면서 통계학과 달라지고 있어요.

    🃏 통계학일까, 기계학습일까? (앞면을 보고 먼저 떠올린 뒤 눌러 뒤집어요)

    통계학

    데이터를 모으고 분석해 규칙성과 불규칙성을 찾고, 이를 바탕으로 예측과 의사 결정을 돕는 학문. 인구 조사에서 시작해 보험·의학·경제·사회학으로 넓어졌어요.

    기계학습

    디지털 기술이 발전하며 늘어난 다양한 형태의 대용량 데이터를 학습해 예측해요. 실시간으로 데이터를 모아 분석하는 일에도 쓰여요.

    03

    통계적 회귀 모델과 기계학습 회귀 모델의 차이

    교과서 133쪽 · 표 Ⅲ-3 · 가설과 검정 · white box · black box

    쉽게 말하면통계적 회귀 모델은 「왜 그런지」를 설명하는 데 강하고, 기계학습 회귀 모델은 「얼마나 정확히 맞히는지」에 강해요. 어느 쪽이 더 좋다기보다 목적과 데이터에 맞게 골라요.

    💬 두 친구의 대화 (교과서 133쪽 대화를 줄여 씀)

    통계적 회귀 모델 편가설을 세우고, 데이터가 통계적 가정을 만족하는지 확인한 뒤 가설검정으로 믿을 만한 결론을 내려. 관계가 우연이 아닌지 따지지. 결과를 해석하기 쉬워서, 원인을 알아야 근본적으로 해결할 수 있는 문제에 좋아.
    기계학습 회귀 모델 편가설이나 검정보다 학습한 데이터로 얼마나 정확하게 예측하는지가 중요해. 텍스트·이미지·영상처럼 복잡하고 큰 데이터도 다뤄. 이유보다 빠르고 정확한 결정이 중요한 상황이 많거든. 대신 해석이 어려워.

    📋 한눈에 비교 (표 Ⅲ-3, 교과서 133쪽을 쉬운 말로 정리)

    구분통계적 회귀 모델기계학습 회귀 모델
    목표변수 사이 관계를 해석하고, 그 관계가 통계적으로 의미 있는지 검정예측의 정확도를 가장 높게
    데이터비교적 적은 양의 데이터대용량 데이터도 효과적으로 처리
    가설과 전제 조건가설을 세우고 통계적 가정을 만족해야 함가설·가정을 세우지 않고, 덜 민감함
    쓰는 모델주로 선형 회귀처럼 해석이 쉬운 모델주로 인공신경망·랜덤 포레스트 같은 복잡한 비선형 모델
    결과 해석원인을 설명하기 쉬움 → white box model예측 성능은 높지만 원인 설명이 어려운 경우가 많음 → black box model

    🗂️ 어느 모델이 알맞을까? (새로 만든 상황 8장)

    상황마다 목적(관계를 설명하고 싶은가, 정확히 맞히고 싶은가)과 데이터(양과 종류)를 따져 골라요.

    04

    마무리

    핵심 문장 · 오늘의 질문 · 마무리 퀴즈 · 생각 정리 질문폼

    공부 시간으로 점수를 예측할 때 y = wx + b의 w는 「1시간 더 공부하면 몇 점 오르나」, b는 「출발점」이다. w와 b를 바꿔 가며 오차 제곱의 평균(MSE)이 가장 작아지는 직선이 그 데이터에 가장 잘 맞는 직선이다.
    수면 시간과 집중도처럼 점들이 산 모양으로 놓이면 어떤 직선을 그어도 오차가 크게 남는다. 이럴 때는 곡선으로 나타내는 비선형 회귀 모델이 필요하다.
    「원인이 무엇인지 설명해야 하는」 동네 정책 자료에는 해석이 쉬운 통계적 회귀 모델을, 「수많은 위성 사진으로 올해 쌀 수확량을 맞혀야 하는」 일에는 기계학습 회귀 모델을 고른다.
