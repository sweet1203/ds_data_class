**확인할 점** (화면에서 바로잡음·선생님 확인)
- **138쪽 옆 설명 「③ 훈련용과 데이터용 데이터셋 분리」** → 「훈련용과 테스트용」으로 바로잡고 01 note에 밝힘(설계안 확인할 점 4).
- **139쪽 ows 설정과 파이썬 코드가 다름**(ows를 Orange 3.40 파이썬으로 열어 properties 확인):
  - Impute: 기본 방법 index 6 = 「Remove instances with unknown values」, total_bedrooms만 따로 index 2 = Average. 파이썬은 중앙값, 오렌지3 Impute에는 중앙값이 없어 평균 → 화면은 Default method를 **Average/Most frequent**로 안내(결측이 total_bedrooms에만 있어 결과는 ows와 같음).
  - Preprocess: Normalize Features method 3 = **Normalize to interval [0, 1]**(MinMaxScaler와 같음) — ows 그대로.
  - Select Columns: target median_house_value, meta ocean_proximity — ows 그대로. Data Sampler: Fixed proportion 80 %, Replicable(seed 42) — ows 그대로.
  - Linear Regression: ows는 reg_type 3 = **Elastic net**(α = 0.0001, L1:L2 = 0.5) → 화면은 **No regularization**(파이썬 LinearRegression과 같게). 확인 결과 R²는 0.606 → 0.611로 거의 같음.
  - Random Forest: ows는 기본 **10그루**(Replicable 안 함) → 화면은 **100그루 + Replicable training**(파이썬 n_estimators = 100과 같게).
  - Neural Network: 100,50 · ReLu · Adam · α 0.0001 · 500번 · Replicable — ows 그대로(파이썬 MLPRegressor 기본값과 같음).
  - Test and Score: ows는 Data Sample만 이어 **교차 검증(Cross validation, 5겹)** → 설계안대로 **Remaining Data → Test Data + Test on test data**(파이썬과 같은 80/20 평가)로 바꾸고 화면 callout에 밝힘.
  - Data Table → Feature Statistics가 Selected Data로 이어진 곳은 File → Column Statistics로 바로 잇고 「Data Table에서 줄을 눌러 고르지 말 것」을 설정 표에 적음(Ⅱ단원과 같음). Feature Statistics는 3.40 이름 Column Statistics + 옛 이름 병기.
- **오렌지3 예상 값**(이 맥 오렌지3 3.40 파이썬으로 같은 흐름을 계산): Test on test data — 선형 회귀 0.606 · 랜덤 포레스트(100그루) 0.810 · 인공신경망 0.673 (랜덤 포레스트 10그루면 0.797). ows 그대로 교차 검증 5겹이면 0.642 · 0.817 · 0.690. 어느 경우든 **랜덤 포레스트가 가장 높고**, 오렌지3에서는 인공신경망이 선형 회귀보다 조금 높게 나옴(교과서 파이썬은 둘이 비슷). 화면은 「값이 달라도 순서를 비교」로 안내, 숫자는 화면에 적지 않음.
- 교과서 139쪽 인공신경망 R² 0.6116은 sklearn 버전에 따라 다르게 나옴(이 맥 sklearn 1.5.2: 0.652). 02 (선택) 코랩 안내에 「0.61~0.65쯤」으로 적음. **코랩 기본 sklearn에서 수업 전 확인 필요.**
- 141쪽 심화(기계학습) 노트북은 학습에 쓴 데이터로 `score`를 매겨 랜덤 포레스트가 0.999로 나옴(과대평가) → 고친 노트북 끝에 훈련/테스트 나누어 다시 비교하는 「더 해 보기」 셀 추가(테스트 R²: 선형 0.946, 랜덤 포레스트 0.992). 화면 (선택) 안내에 「왜 다를지 생각해 봐요」 한 줄.
- 나의 계획 점검: `memoOf('u3-model','plan')`, `memoOf('u3-regression','plan')` — 두 차시가 `plan` 키를 쓰는 것을 check.py가 확인함. 다른 기기에서 썼으면 비어 보여서 「떠올려서 적어요」 안내.
