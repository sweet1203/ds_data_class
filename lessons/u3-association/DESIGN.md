**줄인 것**
- 156쪽 문제 상황 ①~⑤와 그림 Ⅲ-3(연관 규칙 분석 과정)은 화면에 옮기지 않고, 연관 규칙 카드와 sorter로 대신했다.
- 158쪽 「1회·2회·3회」 벤 그림은 계산기의 줄 색칠(A와 B를 함께 산 고객 / A만 / B만)로 대신했다.
- 160쪽 단계별 표(후보·지지도·○×)는 그대로 옮기지 않고, 따라가기에서 「교과서 160쪽 예」를 고르면 같은 표를 학생이 직접 채우게 했다(결과 {B, C, E}가 교과서와 같음).

**확인할 점** (화면에서 바로잡음)
- **155쪽 표 Ⅲ-5 「marker basket analysis」** → market basket analysis(설계안 확인할 점 6). 01 카드와 note에 바로잡았다고 밝힘.
- **159쪽 「향상도 1.05 > 1이므로 … 연관성이 높다」**(설계안 확인할 점 7): 1.05는 1에 매우 가까워 「약하게 관련이 있다」가 알맞다. 157쪽 향상도 해석(>1 연관성 높음)도 정도를 말하지 않아, 화면은 지표 카드와 계산기 해석 문장을 같게 「&gt; 1이면 A를 산 고객이 B를 더 자주 산다 · 함께 사는 경향, 1에 얼마나 가까운지도 함께 봐요」로 쓰고, 1.05는 계산기 아래 note에서 「약하게 관련이 있다」로 바로잡았다(임계값은 두지 않음, 검토 반영). key3 2번도 「향상도는 1에 가깝다」로 씀. 지도서 278쪽도 「연관성이 있다(1.05는 …)」로 적고 있어 수업에서 정도를 함께 말하기를 권함.
- **157쪽 향상도 < 1 「연관성 낮음(… 감소시킬 수 있다)」**: 화면은 「A를 산 고객이 오히려 B를 덜 사요. A 구매가 B 구매를 줄일 수 있어요」로 풀어 씀.
- **160쪽 3-항목 후보 만들기**: 교과서는 「2-항목 빈번 집합의 요소 중 세 개의 요소의 조합」으로 {A,B,C}·{A,B,E}·{A,C,E}·{B,C,E} 네 후보를 모두 센다. 실제 Apriori는 부분집합이 빈번하지 않은 후보({A,B}가 빠졌으므로 {A,B,C} 등)를 세지 않고 바로 빼는데(가지치기), 교과서에 없는 내용이라 화면은 교과서 방식(남은 요소들의 조합을 모두 세기)을 따랐다. 결과는 같다. 수업에서 「{A,B}가 이미 빠졌는데 {A,B,C}가 나올 수 있을까?」를 물어 보면 좋다.
- 159쪽 「스스로 해결하기」 답(삼겹살 → 쌈장 지지도 4/7, 신뢰도 0.8, 향상도 1.4)은 화면 글에 쓰지 않았다. 확인 버튼은 표에서 값을 계산해 맞음/틀림과 힌트만 보여 준다. 계산기의 **쌈장 버튼(A·B 모두)은 잠겨 있다가** 세 칸을 다 맞히거나 세 번 확인하면 열린다(검토 반영, 이 기기에 저장).

**계산 확인**: 계산기 값이 교과서와 같다 — 삼겹살 → 콜라 지지도 3/7 = 0.43, 신뢰도 3/5 = 0.60, 향상도 0.6 ÷ 4/7 = 1.05(159쪽). 따라가기 「교과서 160쪽 예」·최소 지지도 2 → F1 {A}{B}{C}{E}, F2 {A,C}{B,C}{B,E}{C,E}, 최종 {B,C,E}(160쪽과 같음). mlxtend 0.25로도 같은 데이터(min_support 0.3 = 4건 중 2건 이상)에서 같은 빈번 집합 9개.

**지어낸 것(예시 표시)**
- 03 「문구점 (예시)」 거래 5개: 연필·지우개·공책 / 연필·지우개·자 / 공책·풀 / 연필·지우개·공책·풀 / 지우개·공책. 최소 지지도 2 → 최종 {연필, 지우개, 공책}, 모든 단계 빈번 집합 9개(4+4+1) / 3 → 최종 {연필, 지우개}·{지우개, 공책}(3-항목 후보가 2번뿐이라 탈락), 모든 단계 빈번 집합 5개(3+2). **최종 선택 개수는 1개 → 2개로 늘지만 합친 개수는 9개 → 5개로 준다** — 퀴즈 3-2·`apNote`·질문폼 3번·key3는 모두 「합친 개수」 기준으로 맞춤(검토 반영).
- 0 시작 칩(라면·달걀 등), 01 sorter 7장(김밥·컵라면, 연필·지우개, 운동화 → 양말, 소설 1권 → 2권, 개통 → 필름 → 이어폰, 음악 앱, 요리 영상), 퀴즈 상황.
- 교과서 인쇄값(표 Ⅲ-7·8 구매 내역, 160쪽 A~E 거래)은 쪽 표시와 함께 씀.

**선생님 준비물**: 없음(도구 없이 화면만). 다음 차시(u3-association-lab)는 오렌지3 Associate 애드온이 필요하니 수업 전에 설치해 두기.

**검토 반영(1차)**
- 퀴즈 3-2·apNote·질문폼 3번·key3를 「모든 단계의 빈번 집합을 합친 개수」 기준으로 통일, apNote는 최종 선택과 합친 개수를 나눠 적게 함, 따라가기 기록에 합친 개수 추가. 3-2 오답 「달라지지 않는다」 → 「거래 수와 같아진다」.
- 향상도 카드와 계산기 해석 문장 통일(0.1 임계값 문구 삭제).
- 스스로 해결하기 전 계산기 쌈장 잠금.
- sorter 운동화·소설 카드: 쿠폰·알림(추천으로 읽힘)을 빼고 「날짜·시간 순서로 늘어놓아 보니 … 순서」로 고침.
- 퀴즈 3-1 줄기에 「최소 지지도는 2로 정해져 있다」.
