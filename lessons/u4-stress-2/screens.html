쉽게 말하면스트레스 지수처럼 숫자를 예측하는 모델은 예측값이 실젯값에서 얼마나 빗나갔는지로 평가해요. MSE는 빗나간 정도를 제곱해 평균 낸 값이라 작을수록 좋고, R²는 실젯값이 흩어진 정도를 모델이 얼마나 설명하는지라 1에 가까울수록 좋아요.

03

오렌지3로 모델링하고 평가하기

교과서 191~192쪽 · Select Columns · Data Sampler 70% · Linear Regression · Random Forest · kNN · SVM · Test and Score

쉽게 말하면feature는 sleep·exercise·electronic_device_usage, target은 stress로 정해요. 데이터를 훈련 데이터 70%와 테스트 데이터 30%로 나누고, 네 모델을 훈련 데이터로 학습시킨 뒤 모델이 한 번도 보지 않은 테스트 데이터로 평가해요.

진행 체크

🔎 교과서 192쪽 화면과 비교하기

  • 평가 방법이 달라요 · 교과서 화면은 Data Sample(70%)만 Test and Score에 이어 Cross validation(5겹)으로 평가했어요(Linear Regression R² 0.475). 훈련 데이터를 다섯 묶음으로 나눠 돌려 가며 평가한 값이라, 남겨 둔 30%는 쓰이지 않았어요. 오늘은 그 30%를 Test Data로 이어 모델이 보지 않은 데이터로 평가해요.
  • R²가 교과서보다 훨씬 작게 나올 수 있어요 · 테스트 데이터는 19개뿐이고, 그 안에서 스트레스 지수가 좁게 퍼져 있으면 02의 평가 자료 ㉯처럼 R²가 작아져요. MSE와 RMSE도 함께 보고 판단해요.
  • 잘린 target · 이 65개는 Select Rows에서 stress가 36.5를 넘는 학생(40점 두 명)을 뺀 자료예요. 그래서 오늘 결과는 스트레스 지수가 아주 높은 학생을 뺀 자료로 만든 모델의 성능이에요.
  • 정규화 순서 · 교과서처럼 전체 데이터를 먼저 정규화한 뒤 나누면 테스트 데이터의 최솟값·최댓값까지 미리 본 셈이에요. 오늘은 Preprocess를 Preprocessor로 이어 훈련 데이터로만 기준을 정해요. 그래서 stress는 원래 점수(0~40)로 남고, RMSE를 「평균 몇 점쯤 빗나갔는지」로 읽을 수 있어요.
  • 아래쪽 비교 표의 숫자 · Cross validation으로 바꾸면 Test and Score 아래에 모델끼리 비교한 표가 나와요. 숫자는 두 모델 예측값 사이의 MSE가 아니라 행 모델의 점수(MSE)가 열 모델보다 클 확률이에요. MSE는 작을수록 좋으니, 이 값이 작을수록 행 모델이 더 나을 가능성이 커요.

  • 정규화 순서: 원래 코드는 전체 데이터를 정규화한 뒤 나누었어요. 고친 사본은 먼저 나누고, 정규화 기준을 훈련 데이터에서만 구해요.
  • 교차 검증 점수: 원래 코드의 5겹 반복문은 학습만 하고 점수를 계산하지 않았어요. 고친 사본은 교차 검증 평균 점수를 실제로 보여 줘요.
  • 이상치 범위: exercise를 교과서 표처럼 0~145.5로 맞췄어요(원래 코드 0~150, 남는 수는 65개로 같아요). 노트북의 IQR 표는 결측치를 지운 81개로 계산해서 교과서 표와 조금 달라요.
  • 마지막 비교표: 모델끼리 예측값이 얼마나 다른지 보여 주는 표예요. 정확도는 실젯값과 비교한 위 표로 판단해요.
  • 결과 차이: 노트북의 모델 설정(나무 100그루, 이웃 3개 등)과 나누는 방법이 오렌지3와 달라서 숫자가 같지 않아요.
