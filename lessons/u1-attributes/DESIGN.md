퀴즈 12문항(정답 위치 ①4 ②4 ③4). 질문폼 1번 ← 02 판별기·`numTrap`, 2번 ← 03 계산기·교차표·`sexVote`, 3번 ← 04 `sleepTypes`·`relMemo`·`valueMemo`.

**50분 흐름(2차 검토 반영 후)** — 도입(3분) 지난 시간 연결·처음 생각 → 01(5분, 8분까지) 표 누르기, 속성 추가 → **02(11분, 19분까지)** 형태 나무 → 판별기 7개 → 등급 평균 메모(`numTrap`) → 같은 1 두 장 → 03(7분, 26분까지) 계산기로 64일 찾기, 투표 → **04(26분 무렵 시작)** 표 훑기 → ① 관계 메모(`relMemo`)·② 가치 한 문장(`valueMemo`)을 27~31분에 먼저 쓰고 → ③ 짝과 12개 판별·노란 줄 토의(31~39분, 판별하며 ①을 고쳐 써도 됨) → 성취도 → 마무리(8분, 40분 무렵부터) 퀴즈·질문폼.

**줄인 것** — 설계안의 「정리(선택)」 개념 빈칸은 04에 두고, 05는 역량 키우기 원문 순서대로. 역량 키우기 2(중고차)는 교과서 문제와 같은 꼴로 정답을 공개하지 않으려고 메모로만 두고, 자동 채점 연습은 새 예시(자전거 대여)로 바꿈. 단원 「내 실력 점검하기」 표는 칩 3개로. 그림 Ⅰ-3은 원형 배치 대신 2×2 카드로.

**확인할 점**
- **29쪽 속성 판별에서 판단이 갈리는 속성**(화면에서 두 답 인정, 설명 표시)
  - 수면 질(1-10)·스트레스 지수(1-10): 지도서 예시 답은 수치형-이산형. 그런데 27쪽 측주는 「만족도」를 범주-순서형의 예로 들고, 표 Ⅰ-8의 「등급」(1~5 숫자, 간격 일정하지 않음)도 순서형이라 1~10 평가 점수를 순서형으로 보는 학생 답도 근거가 있다 → 이산형·순서형 모두 정답.
  - 혈압(126/83): 지도서는 수치형-연속형. 27쪽 Q3(정수로 표현 → 이산형)을 그대로 적용하면 이산형 → 둘 다 정답. 한 칸에 두 수치(수축기/이완기)가 있다는 점도 설명에 넣음.
  - 신체 활동 수준(분): 지도서는 이산형. 시간은 본래 연속된 양이고 27쪽 측주도 「가격」을 연속형 예로 들어 「정수로 적힘 = 이산형」이 절대 기준은 아님 → 둘 다 정답.
  - 나이·심박수·걸음 수는 이산형만, 체질량 지수는 범주-순서형만(값이 정상·과체중·비만 문자).
- 29쪽 표의 개인 번호 2와 3은 번호만 빼고 모든 값이 같다(원자료의 중복으로 보임). 화면에서는 따로 짚지 않음.
- **30쪽 중고차 데이터의 차량 ID 중복**: 12345(싼타페·A5), 67890(K3·F-150), 34567(모닝·골프)이 서로 다른 차에 두 번씩 쓰였다. 52쪽 학생 ID 중복(설계안 확인할 점 2)과 같은 종류 → 화면 05에 「눈여겨보고 데이터베이스에서 다시 생각」 한 줄만 둠.
- 출석률의 「전체 수업 일수 64일」은 교과서에 없는 값이고, 표 Ⅰ-6의 출석 일수와 출석률(64→1.00, 52→0.81, 58→0.91, 43→0.67, 25→0.39)에서 거꾸로 계산한 것(5명 모두 소수 둘째 자리까지 일치). 화면에는 「64일로 보여요」라고 씀.
- 표 Ⅰ-7은 이름·등급도 범주형, 학년·반·번호도 범주형으로 적는다. 판별기 결과와 일치함.
- 27쪽 「소숫점」 → 화면에는 「소수점」(설계안 확인할 점 5).
- 27쪽 Q1~Q6는 「숫자로 표기하면서 양을 의미?」(Q1)와 「숫자나 문자로 표기하면서 질을 의미?」(Q4)를 따로 두어, 판별기 첫 질문은 두 질문을 한 번에 묻는 꼴(양 / 질)로 합침.
- 시작·05의 「지난 시간에 적은 나의 계획」은 같은 기기·같은 학번으로 u1-data-types를 했을 때만 보인다(로컬 저장값 `ds-u1-data-types-memo` + 학번 접미사를 읽기만 함). 없으면 칸이 숨겨짐.

**지어낸 것(예시 표시)** — 01 학년·반·번호 값(화면에 「예시 값」 표시), 05 자전거 대여 데이터 8개 속성(「새로 만든 예시」 표시), 04 개념 빈칸 세 문장(도서관 대출·혈액형·운동 앱), 메모 자리표시. 교과서 표 값(표 Ⅰ-6, 그림 Ⅰ-3 네 표, 29쪽 수면·건강 4명, 30쪽 중고차 8대, 표 Ⅰ-9)은 쪽 표시와 함께 그대로 씀.

**검토 반영(1차, 독립 검토)**
- 04 나이: 신체 활동·혈압과 달리 이산형만 정답인 까닭을 해설에 밝힘(「햇수를 센 값이라 Q3대로 이산형, 혈압·활동 시간은 재는 양이라 판단이 갈림」). 지도서 예시 답도 이산형.
- 04 빈칸 2번 「수행평가 단계(상·중·하)」 → 「체력 등급(상·중·하)」(학생 화면 금지 낱말).
- 「같은 1, 다른 의미」: 정답이 버튼 순서(명목·순서·연속·이산)와 같던 카드 순서를 섞음(불량품 개수 → 펭귄 성별 → 일치도 → 고기 등급). 앞의 두 장만 펼쳐 두고 나머지 두 장은 (선택) 접기.
- 질문폼 1번 근거: 02 판별기 아래에 「숫자라고 계산해도 될까?」 카드(등급 평균 3 vs 출석 일수 평균 48.4)와 메모 `numTrap` 추가, MEMOLIST에 넣음. 질문폼 1번 문장에도 「등급의 평균을 내 본 것처럼」을 넣음(작업자료 JSON만 고침 — forms.json 다시 반영 필요).
- 04 「개념 정리하기」를 (선택) 접기로. 50분 흐름을 위처럼 고쳐 `relMemo`·`valueMemo`가 30분 무렵에 오게 함.
- 퀴즈: 1-3 보기를 「범주 / 항목 / 특성」으로(정답만 영어 병기하던 것 없앰). 6-2 오답을 「데이터를 빠짐없이 더 많이 모으려고」「속성값을 문자와 숫자로 나누어 적으려고」(표기 방법과 헷갈리는 오개념)로, 6-3 오답을 「데이터의 저장 형식과 용량」「속성마다 알맞은 표기 방법」으로 그럴듯하게. 분포 ①4 ②4 ③4 유지.
- 판별기: 문자 속성(이름·성별 등)을 수치형으로 고르면 「이 속성값은 문자예요. Q1은 숫자로 표기하면서 양을 의미하는지 물어요」라는 힌트로 구분. 「은(는)」「(으)로」는 받침에 따라 조사를 고르는 함수(`josa`)로 정리.
- 점그래프: 오른쪽 끝(출석 일수 55 초과) 점의 이름표를 왼쪽에 붙여 「유선재」가 잘리지 않게(그래프 폭 320 안 확인).
- 05 내 계획 점검: 실제로 보여 주는 것과 맞춤. u1-data-science의 `planLearn`(14쪽)과 u1-data-types의 `plan`(22쪽)을 함께 읽어 보여 주고, 둘 다 없으면 「이 기기에 저장된 앞 시간 계획 메모가 없어요」 안내. 시작 화면은 22쪽 계획만.
