50분 흐름: 시작 3분 → 세 단계 6분(9) → 질문·데이터 7분(16) → 점검실·메모 12분(28) → 친구와 더 생각해 보기(접은 활동)·퀴즈 7분(35) → 마무리·폼 15분. 질문폼 세 문항의 필수 근거 problem·dataCheck를 28분에 마련한다.

줄인 것: 교과서 여섯 분야는 짧은 소개와 카드 세 개로, 구급차 사례·정리 문장·예시 답안은 복사하지 않는다. 실제 수집은 다음 프로젝트에서 한다.

확인할 점: 교과서 180쪽은 정확성의 예로 잘못 입력된 반납 일자, 유효성의 예로 성별 칸의 허용되지 않는 값을 든다. 점검실은 이 구분을 「원래 값과 맞는가 / 속성이 가질 수 있는 값인가」로 풀어 썼다(선택지 이름은 교과서 용어). 식물 개체 수가 유지된 관찰에서 적응의 인과관계를 확정하지 않는다. 정확성은 원본과의 일치, 유효성은 허용 범위로 구별하도록 점검실 문항에 근거를 명시한다. 목적이 달라진 데이터 이용은 동의를 다시 확인한다. 지도서 PDF 305·312~316쪽의 문제 선정·품질 점검·협업 취지를 따른다.

지어낸 것: 도서관 대기·우산 대여·체육관 등 활동 사례와 점검 상황 아홉 개, 퀴즈 전부 독자 제작. 학생 화면에 예시 표시. 교과서의 실습 파일이나 사진은 사용하지 않는다.

선생님 준비물: 외부 파일 불필요. 학생이 학교의 작은 문제 하나를 고를 수 있도록 돕는다.

Layout: 공통 단계 탐색·head/easy/card/quiz/memo/formgo 계승. 질문 → 단계 → 내 문제 → 품질 판단 → 기록 순서. 점검 표는 이차원 정보이므로 자체 스크롤. 색과 서체는 framework 토큰, 추가 CSS는 ps- 접두사. 주요 행동은 상황별 선택과 확인, 결과 메모. 장식용 통계·배지는 넣지 않는다.


검증(2026-11-16, Claude): Codex 초안을 교과서 172~181쪽과 대조. 점검실 선택지를 교과서 용어로 바꾸고 빠져 있던 민감한 개인 정보·편향 상황을 추가, 질문폼 문장의 내부 메모 키 표기를 화면 이름으로 바꿈, 퀴즈 1문항(앞 퀴즈와 겹치는 오차 보완)을 민감 정보 처리로 교체.
