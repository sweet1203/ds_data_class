**확인할 점** (화면에서 바로잡거나 밝힘)
- **ows 설정 확인**(`200쪽_4-2-1_영화관객수예측.ows` XML을 오렌지3 3.40 파이썬으로 풀어 properties 확인): File 877행(영화명·평론가 리뷰 meta) / Group by — gb_attrs `[영화명]`, 숫자·시간 **Mean**, 대표 국적·배급사 **Mode**, 영화명·평론가 리뷰 **Concatenate**(3.40 기본값과 같음) / Scatter Plot — x `실관람객 평점 - Mean`, y `관객 수 - Mean`, show_reg_line 켜짐 / Select Rows — `관객 수 is greater than 3000000`(연산자 번호 4), Select Rows (1) — `관객 수 is below 1000000`(번호 2) / Corpus — Used `평론가 리뷰`, Title `영화명`, Language ko / Preprocess Text — Transformation·Tokenization 기본, Filtering methods [0,3] = **Stopwords + Regexp**, 불용어 파일 `불용어.txt`, Regexp 패턴은 문장부호 목록(Text 애드온 기본식), Document frequency·Most frequent tokens는 꺼짐 / Word Cloud 이름 「고관객군·저관객군 영화 Word Cloud」. 설정 표에 그대로 씀.
- **Text 애드온 미설치**: 이 맥 오렌지3 3.40에는 Orange3-Text가 없어 Corpus·Preprocess Text·Word Cloud 위젯은 **실행 미확인**(XML 설정만 확인). 「Tokens·Types」 숫자, 워드 클라우드 모양은 확인하지 못함. 교과서 202쪽 그림은 Tokens 6588 · Types 4465.
- **Group by의 Mode**(설계안 확인 사항): 대표 국적·배급사 Mode는 설정 표 3번 줄에서 해제하도록 안내(오늘은 숫자 속성과 리뷰만 씀, 다음 차시 회귀 모델에 글자 범주가 들어가지 않게). 교과서 201쪽 그림과 ows에는 Mode가 켜져 있음 — 해제해도 산점도·워드 클라우드 결과는 같음.
- **201쪽 「300만 명 이상」「100만 명 이하」**: 교과서 그림과 ows는 `is greater than`(초과)·`is below`(미만). 영화별 관객 수가 정확히 300만·100만인 영화는 없어 결과가 같으므로, 화면은 위젯 설정 그대로 「넘는」「안 되는」으로 씀.
- **분석 단위**(설계안 확인 사항): 산점도는 Group by(영화 143편) 뒤, Corpus는 File → Select Rows(리뷰 줄) 뒤에 이음(ows 연결 그대로). 화면 01에 「한 줄 = 리뷰 하나」와 sorter로 구별.
- **203쪽 「두 그래프 모두 정비례 관계」**: 산점도의 추세선은 양의 상관을 보여 줄 뿐 정비례(원점을 지나는 비례)나 인과가 아님. 영화 143편 기준 피어슨 r: 실관람객 평점 0.265, 실관람객 평점 참여자 수 0.617(pandas로 계산). 화면·퀴즈 3-1은 「함께 커지는 경향」으로 쓰고, 마무리 key3에 원인이 아님을 밝힘. 참여자 수는 개봉 뒤 쌓이는 값이라는 점은 다음 차시 「예측 시점」에서 다룸.
- **203쪽 「저관객군에서는 ‘새로운’이 더 낮은 빈도」**: 교과서 실습 파일의 리뷰를 \w+로 나누고 소문자 변환·`불용어.txt`·Regexp 패턴으로 걸러 센 값(Orange3-Text 대신 파이썬으로 같은 규칙을 흉내 냄): 「새로운」 고관객군 **24번/리뷰 189개**, 저관객군 **27번/리뷰 385개**. 횟수는 저관객군이 더 많고, 리뷰 100개당은 12.7 vs 7.0. 워드 클라우드 크기는 묶음 안 상대 빈도라 교과서 문장은 상대 빈도로는 맞지만, 표본 수가 다른 두 묶음을 횟수로 견주거나 흥행 원인으로 단정하면 안 됨(설계안). 03 「개수로 비교할까, 비율로 비교할까?」 카드와 퀴즈 3-2·4-3에 반영. 화면에는 집계값만 쓰고 리뷰 원문은 싣지 않음. (같은 방법으로 센 전체 토큰: 고관객군 6,034개·종류 4,343개 / 저관객군 10,854개·7,075개 — 교과서 그림 6588·4465와 조금 다름: 애드온 토큰 규칙 차이로 보임.)
- **202쪽 Tip 「Regexp는 특수 문자를 제거」**(검토 반영): ows의 Tokenization은 `{}`(애드온 기본값)이라 이 맥에서 실제 토큰 규칙을 확인하지 못함(Text 애드온 미설치). Text 애드온의 Regexp 필터는 패턴(문장부호 목록)에 맞는 **토큰**을 걸러 내는 방식이므로, 화면 체험을 「낱말과 문장부호를 따로 토큰으로 나눈 뒤 특수 문자 토큰을 걸러 냄」으로 바꾸고 Regexp를 끄면 「!」「.」 토큰이 빈도에 섞이게 함. 퀴즈 2-2도 같은 동작으로 고침. 체험 아래에 「오렌지3 결과는 토큰 나누기 설정에 따라 조금 다를 수 있어요」 한 줄.
- **200쪽 사이드 「웹크롤링 수집 데이터」 목록**에 순위·관객 수·영화명이 들어 있으나, 본문은 통합전산망 목록을 바탕으로 평점·참여자 수·평론가 평점·리뷰를 웹크롤링한다고 씀. 화면은 본문 기준으로 두 출처를 나눔. 실습 파일에는 상영 횟수·매출액·스크린 수·개봉일·대표 국적·배급사 열도 있음(15열).
- 실습 파일의 영화명 하나(2021·2022년 개봉 두 번)는 같은 이름으로 묶여 숫자가 평균됨 — 143편 중 1편이라 화면에는 쓰지 않음.
