데이터는 새로운 원유
2006년 영국의 수학자 클리브 험비는 데이터를 「새로운 원유(Data is the new oil)」에 비유했어요. 2017년 이코노미스트는 「세계에서 가장 가치 있는 자원은 더 이상 석유가 아닌 데이터」라는 제목의 기사로 세계의 관심을 받았어요. 원유를 가공한 휘발유가 경제와 산업을 바꾸었듯이, 데이터를 정제해서 만든 가치가 경제에 끼치는 영향은 점점 커지고 있어요.

운동을 하거나 TV를 보거나 사진을 올리는 짧은 순간에도 우리는 디지털 흔적을 남겨요. 이렇게 쏟아지는 데이터는 어떤 형태를 가지고 있을까요? 오늘은 급식 사진을 직접 표로 정리해 보며 알아봐요.

01

데이터란 무엇일까?

교과서 23쪽 · 데이터의 뜻 · 데이터의 양과 정보

쉽게 말하면세상에서 일어난 일을 보고(관찰) 재서(측정) 숫자·글·사진·소리 같은 모양으로 적어 둔 것이 데이터예요. 하나만 있으면 별 뜻이 없어 보여도, 많이 모아서 정리하고 분석하면 쓸모 있는 정보가 돼요.

📷 급식 사진을 왜 매일 찍어?

여학생 급식 사진을 왜 매일 찍어?

남학생 급식 데이터를 모으는 중이야. 내 갤러리엔 급식 사진이 무려 365장이나 있지.

생각해 보기 남학생의 사진 데이터만 가지고 급식 재료 중 닭고기의 사용 빈도를 확인할 수 있을까요? 내 생각을 골라 보세요.

사진으로 그날 메뉴는 어느 정도 알 수 있어요. 하지만 사진의 품질이나 요리 방법에 따라 정확하게 판단하기 어렵고, 특히 어떤 재료가 들어갔는지는 확인하기 쉽지 않아요. 게다가 365장을 한 장씩 넘기며 세어야 해요.
02

비정형 데이터를 표로 정리하기

교과서 24쪽 · 비정형 데이터 · 표 Ⅰ-4 · 표 Ⅰ-5 · 반정형 데이터

쉽게 말하면사진·글·영상처럼 정해진 틀 없이 모인 데이터는 바로 세거나 비교하기 어려워요. 그래서 알고 싶은 것에 맞춰 필요한 속성(항목)을 뽑아 행과 열의 표로 정리(구조화)해요.

🧩 비정형 데이터(unstructured data)

급식 사진처럼 특별한 규칙 없이 구성되어 있어 데이터들의 의미나 속성을 한눈에 파악하기 어려운 데이터
소셜 미디어 게시물음성 정보이메일사진영상

이런 데이터는 일정한 형식이나 규칙을 가지지 않아요. 데이터 분석에 쓰려면 속성을 추출하여 구조화하는 과정이 필요해요. 예를 들어 「급식 메뉴에 많이 나오는 고기 반찬은 어떤 종류의 고기일까?」에 답하려면, 사진에서 아래와 같은 속성을 뽑아낼 수 있어요.

✍️ 직접 구조화하기

① 급식 사진에서 메뉴를 뽑아 정리한 표 Ⅰ-4를 보고 ② 표 Ⅰ-5의 고기 종류 칸을 채운 뒤 ③ 닭고기가 나온 날을 세어 봐요.

1 표 Ⅰ-4 급식 메뉴 (교과서 24쪽)

2 표 Ⅰ-5 날짜별 사용된 고기 종류 (0: 미사용, 1: 사용)

칸을 누르면 0 ↔ 1이 바뀌어요. 메뉴 이름을 보고 그 고기를 썼다고 분명히 알 수 있는 칸만 1로 바꾸고, 「확인하기」를 눌러요. 칸을 누르면 위의 표에서 그날 메뉴가 강조돼요.

메뉴 이름에서 고기를 찾아 1로 바꿔 보세요.

3 닭고기가 나온 날은 며칠일까?

표 Ⅰ-5에서 세어 보면일

📋 무엇이 달라졌을까?

표 Ⅰ-4는 급식 메뉴 데이터를 행과 열의 표로 구조화하여 정리한 것이고, 표 Ⅰ-5는 날짜별로 고기 종류를 썼는지(0: 미사용, 1: 사용)를 표로 구조화한 것이에요.

사진 365장에서는 「닭고기」를 찾으려면 한 장씩 보고 판단해야 했지만, 표에서는 닭고기 열의 1만 더하면 돼요.

🔖 더 알아보기 · 반정형 데이터

반정형 데이터(semi-structured data)는 정형 데이터처럼 테이블의 행과 열로 구조화되어 있지는 않지만, 데이터 구조 정보를 포함하고 파일 형식(XML, HTML, JSON)으로 제공하는 데이터예요. 데이터의 형식과 구조가 바뀔 수 있어요. (예: 이메일, 로그 데이터 등)

// 급식 메뉴를 JSON으로 적으면(예시)
{ "날짜": "25-03-05",
  "밥": "잡곡밥",
  "반찬": ["찜닭", "홀그레인 콘샐러드"] }

「날짜」「반찬」 같은 이름표(구조 정보)가 값과 함께 들어 있지만, 날마다 반찬 개수가 달라도 괜찮아요. 이메일은 본문 글은 자유롭게 쓰지만 보낸 사람·받은 시각 같은 구조 정보도 함께 있어서, 교과서 24쪽에서 비정형 데이터의 예(본문)와 반정형 데이터의 예(옆 설명)로 모두 나와요.

03

정형 데이터는 무엇이 좋을까?

교과서 24~25쪽 · 정형 데이터의 뜻과 장점 · 현대 사회의 비정형 데이터

쉽게 말하면행과 열의 표로 깔끔하게 정리된 데이터는 컴퓨터가 바로 찾고, 다시 줄 세우고, 계산할 수 있어요. 그래서 사진·영상 같은 데이터도 분석하려면 목적에 맞게 표로 바꾸는 과정이 꼭 필요해요.

📋 정형 데이터(structured data)

표 Ⅰ-4, 표 Ⅰ-5와 같이 규칙에 따라 정리된 명확한 형태나 구조로 이루어진 데이터. 주로 행과 열로 표현할 수 있는 표 형태로 구성된다.
🔎

정리 · 검색 · 재정렬 · 저장

원하는 값을 쉽게 찾고, 기준에 따라 다시 줄 세우고, 저장할 수 있어요.

🔗

다른 정형 데이터와 결합

날짜처럼 같은 속성이 있으면 다른 표와 쉽게 이어 붙일 수 있어요.

🧮

통계 분석 · 연산

명확한 구조가 있어서 컴퓨팅 도구로 통계 분석을 하거나 삽입, 삭제, 수정, 검색 등의 연산을 비교적 쉽게 할 수 있어요.

데이터 분석에 흔히 쓰는 스프레드시트 파일, CSV 형식의 파일로 저장·관리되는 데이터는 대부분 정형 데이터예요.

⚙️ 표 Ⅰ-5로 직접 해 보기

버튼을 눌러 정형 데이터로 할 수 있는 일을 해 보세요. 같은 일을 급식 사진 365장으로 한다면 얼마나 걸릴지 떠올려 봐요.

📡 현대 사회에는 비정형 데이터가 더 많아요 (그림 Ⅰ-2를 글로 바꿈)

과거에는 데이터 분석에 쓰는 데이터 대부분이 정형 데이터였어요. 하지만 지금은 사람들이 주로 스마트폰, 소셜 미디어, 채팅, 영상 통화, 실험 등으로 의사소통을 하고, 이 과정에서 생기는 것은 대부분 비정형 데이터예요.

04

스스로 해결하기 · 정형일까, 비정형일까?

교과서 25쪽 · 데이터를 정형 데이터와 비정형 데이터로 구분하고 그 이유 말하기

쉽게 말하면겉모습이 표처럼 보이는지만 보지 말고, 정해진 규칙에 따라 행과 열로 정리되어 있어서 컴퓨터가 바로 분석할 수 있는지를 따져 봐요.

🗂️ 네 가지 데이터를 구분해 보자 (교과서 25쪽 자료를 다시 그림)

데이터마다 정형 또는 비정형을 고른 뒤 「확인하기」를 눌러요.

네 가지를 모두 고르면 확인할 수 있어요.
🎯 (선택) 한 걸음 더 · 내 주변의 데이터 시간이 있으면 열어요

카드에 적힌 데이터가 정형 데이터인지 비정형 데이터인지 골라요. (모두 새로 만든 예시예요)

📝 (선택) 개념 정리하기 빈칸 세 문장

빈칸에 들어갈 말을 먼저 떠올린 뒤 눌러서 확인하세요.

  1. 체육 대회 날 찍은 사진 300장은 일정한 형식이나 규칙이 없어 의미를 한눈에 파악하기 어려운 이다. 이 사진들로 「어느 반이 가장 많이 웃었을까?」를 알아보려면 필요한 을 뽑아 하는 과정이 필요하다.
  2. 반 친구들의 줄넘기 기록을 이름·횟수 열로 정리한 표는 이므로, 컴퓨팅 도구로 가장 많이 넘은 친구를 찾거나 평균을 구하기 쉽다.
  3. 데이터 구조 정보를 담은 JSON 파일처럼, 표의 행과 열은 아니지만 구조 정보가 함께 들어 있는 데이터를 라고 한다.

05

마무리

데이터는 관찰과 측정을 통해 얻은 실질적인 값으로, 사실을 기호·숫자·문자·이미지·소리·동영상 등으로 기록한 것이다. 저장, 가공, 분석을 거쳐 유의미한 정보가 된다.
비정형 데이터는 특별한 규칙 없이 구성되어 의미나 속성을 한눈에 파악하기 어려운 데이터(사진, 영상, 게시물 등)로, 분석하려면 속성을 추출하여 구조화해야 한다.
급식 메뉴를 날짜·고기 종류 열로 정리한 표 Ⅰ-5처럼 행과 열로 정리된 정형 데이터는 컴퓨팅 도구로 찾기, 더하기, CSV로 저장하기가 쉬워서, 사진 365장을 넘겨 보지 않고도 닭고기가 나온 날을 바로 셀 수 있다.
