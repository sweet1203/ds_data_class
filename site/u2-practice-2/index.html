🔟

도시는 10개뿐

숙소 5만여 개가 아니라 10개 도시의 평균끼리 구한 상관계수예요. 점이 10개뿐이면 무슨 일이 생길지, 산점도에서 한 도시를 가려 보며 생각해 봐요.

🔁

상관관계 ≠ 인과관계

두 속성이 함께 움직여도 하나가 다른 하나의 원인이라고 할 수는 없어요(97쪽 더 알아보기).

🏅

Rank 줄은 따로

Rank는 순위라 작을수록 비싼 도시예요. 다른 지수와 부호가 반대로 나와요.

교과서는 고객 만족도를 어떻게 해석했을까? (내 메모를 쓴 뒤에 펼쳐요)
  • 고객 만족도는 청결도, 숙박 인원과 양의 상관관계를 보여, 청결하고 넓은 숙소가 만족도의 주요 평가 대상이라고 짐작해요. 다만 숙박 인원의 상관계수는 청결도보다 0에 훨씬 가까워 「높다」기보다는 중간 정도예요.
  • 고객 만족도는 임대료 지수, 생활비+임대료 지수와 음의 상관관계를 보여, 임대료가 높은 도시에서 숙소의 만족도가 떨어지는 경향이 있다고 해석해요.

진행 체크

📖 교과서는 어떻게 판단했을까? (내 순위를 정한 뒤 비교해요)
  • 숙소를 중심으로 보면 청결도와 고객 만족도가 높고 도심 거리와 1인당 숙박비가 낮은 아테네가 알맞은 여행지예요.
  • 생활비와 숙소를 모두 보면 생활비 지수와 1인당 숙박비가 낮고 고객 만족도도 높은 편인 부다페스트가 알맞아요.
  • 반면 런던은 생활비 지수와 도심 거리가 높고 청결도와 고객 만족도가 낮아, 꼭 가야 할 관광지가 있는 것이 아니라면 그리 추천할 만한 여행지는 아니라고 판단해요.

2. 도시를 지도에 나타내 보기

교과서는 오렌지3 Geo 애드온의 Geocoding(지역명을 위도·경도 좌표로 바꿈)과 Geo Map 위젯을 써요. 애드온을 설치하려면 인터넷과 설치 권한이 필요하니 선생님과 함께 해요. 설치가 어렵다면 아래 화면 안 좌표 지도로 해요.

오렌지3 Geo 애드온으로 하기
  1. 메뉴 Options → Add-ons…에서 Geo를 체크하고 설치한 뒤 오렌지3를 다시 열어요.
  2. Merge Data에 Geocoding을 연결 → Encode region names into geographical coordinates, Region identifier는 city, Identifier type은 Major city (Europe)
  3. Geocoding에 Geo Map을 연결(Coded Data → Data) → Color는 city, Size에 모둠원 기준 속성을 한 번씩 넣어 비교해요.
점 크기도시를 눌러 세 곳까지 고르면 서로 떨어진 거리가 나와요.

점 위치는 도시 중심의 위도·경도(널리 알려진 값)를 가로·세로 좌표로 찍은 것이고, 거리는 두 좌표 사이의 직선거리를 대략 계산한 값이에요. 실제 이동 거리와는 달라요.

📊 내 실력 점검하기

「예」라고 답할 수 있는 것을 모두 골라요. 모두 고를 수 있으면 심화, 아니면 보충 활동을 해 봐요.

🧩 보충 · 심장 질환 데이터의 상관관계

오렌지3 Datasets 위젯에서 내장 데이터 Heart Disease를 불러와 Correlations로 속성 간 상관계수를 구해요. 상관계수는 1이나 −1에 가까울수록 강하고, 0에 가까울수록 약한 상관관계예요.

🚀 심화 · 나라별 물가 지도 (Geo 애드온 필요)

생활비 File → Geocoding(Country로 좌표 찾기) → Choropleth Map으로 나라별 생활비 지수를 색으로 칠해요. 짝을 못 찾은 나라(UnitedKingdom처럼 붙여 쓴 이름 등)는 Geocoding 창 오른쪽 목록에서 직접 골라 줘요. 데이터값에 따라 해당 영역의 색을 다르게 칠하는 위젯이에요.

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

숙소 데이터와 생활비 데이터는 도시라는 공통 속성으로 이어 붙였어요. 이름이 일치하는 도시만 짝지어져 10줄이 되었고, 표기가 다르면 짝을 찾지 못하니 형식을 먼저 맞춰야 해요.
합친 데이터의 산점도에서 1인당 숙박비가 높은 도시는 생활비 지수도 높은 쪽에 모였고, 상관계수로 그 방향과 강도를 숫자로 확인했어요. 도시가 10개뿐이고 상관이 원인을 뜻하지는 않는다는 점도 함께 따졌어요.
단위가 다른 속성을 0~1로 바꾸어 히트맵으로 색칠하니 도시마다 강점과 약점이 한눈에 보였어요. 어떤 속성을 기준으로 삼느냐에 따라 고른 여행지가 달라졌어요.

오늘의 질문에 답하기

지난 시간과 오늘 한 일(데이터 수집 → 속성 파악 → 새 속성 → 통합 → 관계 분석 → 정규화·히트맵)을 떠올리며 답해 보세요.
