몇 시간 자는지, 얼마나 움직이는지, 전자 기기를 얼마나 쓰는지 같은 하루의 기록도 데이터예요. 이런 데이터를 설문으로 모으면 또래 친구들이 겪는 스트레스와 어떤 관계가 있는지 살펴볼 수 있어요.

오늘은 데이터 과학 프로젝트의 앞 단계인 문제 정의 → 데이터 수집 → 데이터 전처리를 해요. 설문 문항을 다듬고, 예제 파일을 오렌지3로 불러와 결측치와 이상치를 처리하고 정규화까지 해요.

앞에서 배운 데이터 과학 프로젝트 단계를 실제 주제에 적용해요. 오늘 다루는 파일은 교과서가 준비한 예제 데이터예요. 내 스트레스를 진단하는 활동이 아니라 프로젝트 과정을 연습하는 분석이에요. 요즘 마음이 많이 힘들다면 선생님이나 상담 선생님께 꼭 이야기해 주세요.

처음 생각

스트레스에 영향을 줄 것 같은 일상 데이터는? 여러 개 골라도 돼요.

핵심 질문
  • 교과서 질문 · 나와 또래 친구들이 겪는 어려움을 데이터로 해결해 본다면 어떤 문제를 선정할 수 있을까? 또 어떤 데이터가 필요할까?
  • 오늘의 질문 · 스트레스 지수를 예측하려면 데이터를 어떻게 모으고, 분석하기 전에 어떻게 다듬어야 할까?
배우고 나면 할 수 있는 것
  • 데이터 과학으로 문제를 해결하기 위해 데이터를 수집하고 탐색적으로 분석할 수 있다.
  • 문제 해결을 위해 수집한 데이터를 데이터 과학 프로젝트 단계를 바탕으로 수행할 수 있다.
01

문제 정의와 설문 문항 만들기

교과서 183~184쪽 · 문제 정의 · 선택지 제시 · 입력 단위 · 설문 시 주의 사항

쉽게 말하면스트레스에 영향을 주는 일상 데이터를 찾으려면 먼저 데이터를 모아야 해요. 친구들에게 설문을 할 때 답이 제각각이면 나중에 고치느라 고생해요. 그래서 선택지를 주고 단위를 밝히고, 왜 모으는지 알려야 해요.

❓ 문제 정의

통계청 조사에서 청소년이 삶을 포기하고 싶다고 느끼는 가장 큰 원인 중 하나로 우울감이 나타났어요. 우울감은 스트레스의 대표적 증상이고, 스트레스로 어려움을 겪는 청소년도 늘고 있어요(교과서 183쪽 그림 Ⅳ-1). 그래서 이 프로젝트의 문제는 이렇게 정해요.

💡 일상생활의 데이터 중 스트레스에 영향을 줄 수 있는 것은 무엇일까?

교과서 예제에서 모은 데이터: 학년(1~3) · 스트레스 지수(0~40, 스스로 진단해 입력) · 수면 시간(시간) · 운동 시간(분) · 전자 기기 사용 시간(시간)

📝 설문 문항, 이렇게 고쳐요

선택지 주기

답이 여러 형식으로 나올 수 있는 문항은 고를 수 있는 선택지를 줘요.

단위 밝히기

「분」과 「시간」처럼 단위가 섞일 수 있는 문항은 입력 단위를 정해 줘요.

개인 정보 줄이기

분석에 필요하지 않은 개인 정보는 묻지 않아요.

목적 알리기

데이터를 왜 모으는지 밝히고, 편안하고 솔직하게 답할 수 있게 해요.

🗂️ 이 문항은 어떻게 고칠까? (6장 · 새로 만든 예시 문항)

✍️ 우리 모둠 설문 문항 만들기

스트레스 지수 예측에 쓸 문항 두 개를 직접 만들어요. 하나는 선택지가, 하나는 단위가 들어가게 쓰고, 설문지 첫머리에 넣을 수집 목적 안내 한 문장도 써요. 교과서의 학년·수면 시간 문항 말고 새 문항으로 써 보세요.

🧮 결측치 비율, 무엇을 기준으로 셀까?

칸 기준

📏 정규화하기 · Normalize to interval [0, 1]

속성마다 단위와 크기가 달라요(스트레스 지수는 0~40, 운동 시간은 0~수백 분). 남은 값을 (값 − 최솟값) ÷ (최댓값 − 최솟값)으로 바꾸면 모두 0~1 사이가 되어 같은 눈금에서 비교할 수 있어요.

🆘 막혔을 때 펼쳐 보기
  • Select Rows에서 속성 이름이 안 보여요 → Select Rows를 File이 아니라 Impute 뒤에 이었는지, Impute 아래 상태 줄에 데이터가 나가고 있는지 확인해요.
  • 남은 수가 교과서와 달라요 → 조건마다 is between을 골랐는지, 소수점(36.5, 145.5)을 바르게 넣었는지 확인해요. 조건 하나라도 빠지면 남는 수가 달라져요.
  • Data Table (1)의 값이 0~1이 아니에요 → Preprocess에서 Normalize to interval [0, 1]을 골랐는지, 다른 정규화 방법(μ=0, σ²=1)이 골라져 있지 않은지 확인해요.
  • Box Plot에 상자가 안 보여요 → 왼쪽 Variable 목록에서 숫자 속성을 눌러 골라요. Subgroups는 None으로 둬요.
  • 오렌지3가 안 열려요 → 03의 탐색기로 같은 과정을 해 보고, 기록 칸에 「(탐색기)」라고 적은 뒤 탐색기 결과를 써요.
05

마무리

핵심 문장 · 오늘의 질문 · 마무리 퀴즈 · 생각 정리 질문폼

스트레스 설문 문항에 선택지와 단위를 넣고 수집 목적을 밝히면, 모인 답을 고치는 일이 줄고 응답자도 안심하고 답할 수 있다.
예제 파일의 빈 칸은 415칸 중 2칸이지만 지워지는 행은 83개 중 2개라서, 무엇을 기준으로 세느냐에 따라 결측치 비율이 달라 보였다.
상자 그림의 IQR 기준선과 속성에서 있을 수 있는 값의 범위를 함께 보고 Select Rows 조건을 정했고, 정규화로 남은 값을 0~1 눈금에 맞췄다.
