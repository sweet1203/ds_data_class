01

기계학습 회귀분석 단계 · Min-Max 스케일링

교과서 138쪽 · 그림 Ⅲ-2 · 데이터 수집 및 전처리 · Min-Max 스케일링

쉽게 말하면기계학습을 통한 회귀분석은 데이터에서 패턴을 학습해 집값 같은 연속적인 값을 예측해요. 「영향이 있나?」를 검정하는 게 목적이 아니라서 가설 설정과 가설검정이 필요 없어요. 대신 여러 모델의 성능을 비교해요.

🪜 기계학습을 통한 회귀분석 단계

① 가설 설정필요 없다.
→
② 데이터 수집 및 전처리통계적 회귀분석과 같은 데이터를 쓰고, 스케일링을 더한다.
→
③ 모델 생성 및 학습회귀 모델을 만들고 데이터로 학습시킨다.
→
④ 가설검정필요 없다.
→
⑤ 평가모델들 사이의 성능을 평가한다.

그림 Ⅲ-2(교과서 138쪽)와 같은 단계를 새로 그렸어요.

📐 Min-Max 스케일링 체험 (지역 다섯 곳의 값은 연습용 예시예요)

방 개수는 수천 단위, 중간 소득은 한 자리 수처럼 변수마다 값의 범위(scale)가 달라요. 이 차이가 모델 성능에 영향을 줄 수 있어서, 변수마다 최솟값은 0, 최댓값은 1이 되게 바꿔요. 75쪽에서 배운 최소-최대 정규화와 같은 계산이에요.

변환한 값 = (값 − 최솟값) ÷ (최댓값 − 최솟값)

원래 값 (칸을 고쳐 보세요)

0~1로 바꾼 값

02

모델 생성 및 학습 · 평가

교과서 138~139쪽 · 선형 회귀 · 랜덤 포레스트 · 인공신경망 · 결정 계수 비교

쉽게 말하면같은 훈련용 데이터로 세 모델을 학습시키고, 처음 보는 테스트용 데이터의 집값을 예측하게 해요. 실제 집값과 예측한 집값이 얼마나 가까운지를 결정 계수(R²)로 비교해요.

🤖 세 가지 회귀 모델

📈

선형 회귀

독립 변수와 종속 변수 사이의 선형 관계를 찾는 가장 기본적인 회귀 모델이에요. 직선으로 예측해요.

🌲

랜덤 포레스트

앙상블 학습 기법 가운데 하나로, 여러 개의 결정 트리를 학습시켜 그 결과를 결합해 예측해요. 모델의 안정성과 정확성을 높여요.

🧠

인공신경망

딥러닝 기법을 활용한 회귀 모델로, 여러 은닉층을 통해 데이터 사이의 복잡한 관계를 학습해요.

코드 속 설정 (교과서 138쪽)뜻
RandomForestRegressor(n_estimators = 100)결정 트리 100개를 만들어 예측에 써요.
MLPRegressor(hidden_layer_sizes = (100, 50))첫 번째 은닉층에 뉴런 100개, 두 번째 은닉층에 50개가 있어요.
max_iter = 500최대 500번까지 학습을 반복해요.

🎯 실젯값–예측값 산점도 (테스트 지역 36곳의 예시 값 · 모델을 바꿔 보세요)

가로축은 실제 집값, 세로축은 모델이 예측한 집값이에요. 점이 대각선(실젯값 = 예측값) 위에 있으면 정확히 맞힌 거예요. 세 모델을 모두 눌러 점들의 퍼진 모양과 R²를 비교하세요.

🆘 막혔을 때 펼쳐 보기
  • Test and Score에 Test Data 선이 안 생겨요 → Data Sampler에서 Test and Score로 선을 한 번 더 끌어요. 뜨는 창에서 Remaining Data와 Test Data를 이어요. 이미 이은 선은 두 번 클릭하면 고칠 수 있어요.

04

「데이터 모델과 회귀분석」 정리

교과서 140~141쪽 역량 키우기 · 두 회귀 모델의 결과 해석 · 나의 계획 점검 · (선택) 독립·종속 변수 · 보충·심화

쉽게 말하면회귀분석의 출발은 무엇으로(독립 변수) 무엇을(종속 변수) 예측할지 정하는 거예요. 그다음 목적이 「영향 확인」이면 통계적 회귀, 「정확한 예측」이면 기계학습 회귀 결과를 중심으로 읽어요.

🚲 새 상황에서 두 모델의 결과 읽기 (공공 자전거 대여소 · 예시 결과)

집값 예측에서는 「영향이 있나?」를 묻지 않으므로 가설 설정·가설검정 없이 데이터를 준비해 학습시킨다. 방 개수와 중간 소득처럼 범위가 크게 다른 변수는 Min-Max 스케일링으로 0~1에 맞추는데, 아주 큰 값 하나가 있으면 나머지가 0 쪽으로 몰린다.
실젯값–예측값 산점도에서 점들이 대각선에 바싹 모인 모델일수록 R²가 1에 가까웠다. 결정 트리 여러 개를 묶은 랜덤 포레스트가 이 데이터에서 가장 높았고, 은닉층이 있는 인공신경망이 늘 앞서지는 않았다.
오렌지3에서는 Impute → Preprocess → Select Columns → Data Sampler로 준비하고, Test and Score에서 남겨 둔 20%로 세 모델을 겨룬다. 값은 파이썬과 조금 달라도 모델 순서를 비교해 고른다.
