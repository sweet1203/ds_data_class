결측치와 이상치를 찾아 처리하는 방법, 두 데이터를 합치는 통합, 단위를 맞추는 표준화를 개념으로 배웠어요. 오늘은 시험 기간에 잠이 모자란 수현이의 고민(70쪽)처럼 수면의 질과 스트레스를 살펴보려고, 실제 수면 데이터에 이 방법을 오렌지3로 직접 적용해 봐요.

🩹 결측치를 채우는 방법

오렌지3의 Impute 위젯은 결측치를 여러 방법으로 처리할 수 있어요. 오늘은 Average/Most frequent(평균값 또는 최빈값)로 채워요. 수치형 속성은 평균값, 범주형 속성은 최빈값으로 채워져요.

Default Method 7가지 모두 보기 (펼쳐 보기)
  • Don’t Impute · 아무것도 입력하지 않음
  • Average/Most frequent · 평균값 또는 최빈값 사용 오늘 쓸 방법
  • As a distinct value · 새로운 값으로 대체
  • Fixed values · 고정된 값으로 대체
  • Model-based imputer · 다른 측정으로 예측 모델을 만들어 가장 비슷한 값을 고름
  • Random values · 속성의 분포를 계산한 뒤 그 분포에서 무작위로 고름
  • Remove instances with unknown values · 결측치가 있는 데이터(줄) 제거

아래쪽 Individual Attribute Settings에서는 속성마다 처리 방법을 다르게 정할 수 있어요.

02

이상치를 찾아 처리해 보자

교과서 79~80쪽 · Box Plot · Formula · Select Rows · Column Statistics

쉽게 말하면박스 플롯으로 사분위수 범위(IQR)를 구해 하한값·상한값을 정하고, 그 범위를 벗어난 값을 이상치로 봐요. Formula로 줄마다 「이상치인가?」 표시(Y/N)를 붙이고, Select Rows로 N인 줄만 남겨요.

📦 박스 플롯으로 범위 정하기

신체 활동 수준(Physical Activity Level)의 박스 플롯을 그리면 제1사분위수(Q1)는 45, 제3사분위수(Q3)는 75예요(교과서 79쪽).

사분위수 범위(IQR)75 − 45 = 30
하한값45 − (30 × 1.5) = 0
상한값75 + (30 × 1.5) = 120

하한값(0)과 상한값(120)의 범위를 벗어난 데이터를 이상치로 볼 수 있어요. 박스 플롯은 범주별로 수치 데이터를 비교할 수 있도록 분포(중앙값, 사분위수 등)를 보여 주는 그래프예요.

🧮 Formula 식 읽기

outlier라는 새 범주형 속성을 만들고, 식과 Values를 이렇게 넣어요.

0 if Physical_Activity_Level > 120 else 1
Values: Y, N → 0번 값 = Y, 1번 값 = N

신체 활동 수준을 바꾸어 보며 어떤 값에 Y가 붙는지 확인해요.

60
📌 교과서 80쪽 설명 바로잡기 · 교과서 문장은 「120을 넘지 않으면 0번 값」이라고 적혀 있지만, 식 0 if … > 120 else 1은 120을 넘으면 0번 값(Y = 이상치), 넘지 않으면 1번 값(N)이에요. 위의 막대로 확인해 보세요.

교과서 80~81쪽 그림에서는 표준화할 5개를 고른 위젯이 Select Columns, 나머지 6개를 고른 위젯이 Select Columns (1)이에요(교과서 ows 파일에는 이름이 반대로 저장되어 있어요). 위젯 이름 뒤 번호는 만든 순서대로 붙으니 내 화면과 달라도 괜찮아요.

💡 교과서 그림은 Data Table (3)·Data Table (4)를 거쳐 다음 위젯으로 이어요. 그렇게 해도 되지만 Data Table에서 줄을 눌러 고르면 고른 줄만 넘어가요. 이 흐름도처럼 Select Rows·Preprocess에서 바로 이으면 더 안전해요.
