데이터 기반 의사 결정이란?

교과서 18쪽 · 뜻, 중요성, 사례

쉽게 말하면느낌만 믿고 고르지 않고, 문제와 관련된 데이터를 보고 문제를 깊이 이해한 다음 가장 합리적인 해결 방법을 고르는 것이 데이터 기반 의사 결정이에요.

📘 데이터 기반 의사 결정 (18쪽)

데이터 기반 의사 결정이란 문제와 관련된 데이터를 통해 문제를 심층적으로 이해하고 합리적인 해결 방안을 마련하는 것을 말한다.

02

데이터 기반 의사 결정은 어떤 과정을 거칠까?

교과서 19쪽 · 나이팅게일, 계획 → 수집 → 분석 → 적용

쉽게 말하면「데이터 과학」이라는 말이 없던 1854년에도 나이팅게일은 데이터로 병사들의 목숨을 구했어요. 그 과정을 따라가 보면 계획 → 수집 → 분석 → 적용의 네 단계가 보여요.

🏥 나이팅게일이 수집한 데이터 (19쪽 표 Ⅰ-3)

1854년 크림 전쟁에 간호사로 참여한 나이팅게일은 병사들이 죽는 주요 원인을 확인하려고 아래와 같은 데이터를 모았어요. 기초 데이터는 그달의 원인별 사망자 수, 누적은 그달까지 모두 더한 수예요.

🪜 데이터 기반 의사 결정 과정 (19쪽)

나이팅게일이 1854~1856년 동안 모은 데이터는 야전 병원에서 숨진 환자들이 부상보다 전염병으로 숨진 경우가 많다는 사실을 발견하는 기초가 되었어요. 나이팅게일은 데이터와 야전 병원의 환경을 함께 관찰해 비위생적인 환경이 전염병의 원인이라고 판단했지요.

계획문제와 관련한 가설과 필요한 데이터 수집 계획 세우기

「환자의 주요 사망 원인이 부상이 아닐 수 있다.」라는 가설을 바탕으로 환자의 데이터를 모을 계획을 세웠어요.

수집계획에 따라 데이터를 수집하여 정리하기

환자의 상처와 원인, 치료 과정, 사망 원인 등을 기록한 세계 최초의 의무 기록표(표 Ⅰ-3)를 만들어 체계적으로 모으고 관리했으며, 그래프로 시각화해 정리했어요.

분석데이터의 적절한 분석을 통하여 현상 이해하기

부상보다 전염병으로 숨진 환자가 더 많다는 사실을 밝혔어요.

적용문제 해결에 적용하여 상황 개선하기

병원 위생 상태가 취약하다는 것을 알리며 병원 환경 개선을 요구한 결과, 부상병의 사망률이 42%에서 2.2%까지 줄었어요.

눈여겨볼 점은 한 사람의 뛰어남보다, 데이터를 모으고 분석해 결정에 쓴 과정이에요. 수치만 보지 말고 그 데이터가 나온 맥락(야전 병원의 환경)까지 함께 살펴본 거예요.

🧩 (선택) 순서대로 놓아 보기 예시 상황 · 시간이 남으면 펼쳐요

(예시) 어느 학교 학생회가 급식 잔반을 줄이려고 데이터를 활용했어요. 카드를 계획 → 수집 → 분석 → 적용 순서대로 눌러요.

03

데이터를 무엇에 활용할까?

교과서 20~21쪽 · 설명, 진단, 예측, 처방

쉽게 말하면데이터로 결정할 때는 무엇이 궁금한지에 따라 목적이 달라져요. 이미 일어난 일을 알고 싶은지, 그 까닭을 알고 싶은지, 앞으로 일어날 일을 알고 싶은지, 원하는 결과를 만들 방법을 알고 싶은지 생각해 봐요.

🧭 데이터 과학의 주요 활용 목적 (20쪽)

데이터를 기반으로 의사 결정을 할 때, 설명, 진단, 예측, 처방과 같은 목적을 위해 데이터 과학을 활용할 수 있어요.

무슨 일이 일어났나?

설명

데이터를 기반으로 현재 상태나 발생한 상황을 확인하거나, 지난 결과 데이터를 분석해 어떤 일이 발생했는지 정확하게 파악하는 것이 목적이에요.

왜 그런 일이 일어났나?

진단

데이터를 기반으로 왜 그런 일이 일어났는지 발생 이유를 찾아요. 특이한 현상이나 사건이 왜 생겼는지 원인을 찾는 것이 목적이에요.

향후 무슨 일이 일어날까?

예측

지나간 결과를 분석해 어떤 일이 발생할지 예측하는 것이 목적이에요.

어떻게 해야 목표한 일이 일어날 수 있나?

처방

목표한 바가 이루어지도록 상황의 원인이 되는 요소들을 제어하는 방법을 찾아내는 것이 목적이에요.

네 가지 목적은 꼭 정해진 순서대로만 쓰이는 게 아니라, 상황에 따라 되풀이되고 서로 이어져요.

🎯 이 분석의 목적은?

교과서 20쪽의 학습 데이터 예시를 바꿔 쓴 카드예요. 「데이터 ▶ 알고 싶은 것」을 읽고 목적을 골라요. 같은 데이터가 두 번 나오는 카드도 있으니 화살표 뒤를 잘 봐요.

이처럼 데이터의 잠재력을 이해하고 이를 바탕으로 데이터 기반 의사 결정을 내리는 문제 해결 능력은 디지털 사회의 필수적인 역량이에요.

04

함께 해결하기 · 데이터 기반 의사 결정 사례

교과서 21쪽 · 조사 · 발표

쉽게 말하면경제나 스포츠처럼 실제 현장에서 데이터로 결정을 내린 사례를 찾아, 어떤 데이터를 어떤 목적으로 썼는지 정리하고 발표해요.
🔎 조사 방법 선생님이 알려 주는 사이트나 뉴스 검색에서 「경제 데이터 분석 사례」, 「스포츠 데이터 분석」처럼 찾아봐요. 모둠 안에서 분야를 나눠 조사하면 발표 시간을 아낄 수 있어요.

📝 내가 찾은 사례 정리하기

꼭 쓸 것: 1. 사례, 2. 활용된 데이터, 3. 목적 칸 가운데 1~2칸. 나머지 칸은 시간이 남으면 채워요.

분야

3. 데이터를 분석해 설명, 진단, 예측, 처방에 어떻게 활용했나요? 찾은 목적 1~2칸만 써도 돼요. 찾지 못한 목적은 비워 둬요.

우리 반 학급 텃밭에서 채소를 잘 키우고 싶다고 생각해 봐요. 모둠에서 이야기 나눈 뒤 위 칸에 채워요.

  1. 어떤 데이터를 모을 수 있을까요? (누가, 언제, 무엇을 기록할지)
  2. 그 데이터로 무엇이 일어났는지, 왜 그랬는지, 앞으로 어떨지, 어떻게 하면 좋을지 하나씩 말해 봐요.
  3. 이 결정이 「감」으로 정할 때와 무엇이 다른지 비교해요.

05

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

데이터 기반 의사 결정은 문제와 관련된 데이터를 통해 문제를 심층적으로 이해하고 합리적인 해결 방안을 마련하는 것이다. 데이터는 현실적이고 객관적인 정보를 제공해 의사 결정의 오류를 최소화한다.
데이터 기반 의사 결정은 계획 → 수집 → 분석 → 적용의 과정을 거친다. 나이팅게일은 사망 원인 데이터를 기록하고 시각화해 전염병이 주요 원인임을 밝히고, 병원 환경을 개선해 사망률을 줄였다.
데이터 과학은 설명(무슨 일이), 진단(왜), 예측(앞으로 무슨 일이), 처방(어떻게 해야)의 목적으로 활용되며, 불확실성을 줄이고 의사 결정의 시간과 비용을 절감한다.

  2. 나이팅게일의 데이터(표 Ⅰ-3)를 그래프로 비교해 보았습니다. 그래프에서 알 수 있는 사실을 수치를 들어 쓰고, 나이팅게일이 계획 → 수집 → 분석 → 적용의 과정을 거쳐 어떤 결정을 내렸는지 설명하세요.
  3. 「이 분석의 목적은?」에서 학습 데이터 카드를 설명·진단·예측·처방으로 나누고, 같은 데이터가 두 목적에 쓰인 짝 하나를 골라 적었습니다. 그 짝을 예로 들어 네 목적의 차이를 설명하세요. 함께 해결하기에서 조사한 사례가 있다면 어떤 목적에 해당하는지 덧붙이세요.
