아현이의 고민
대학에 들어가면 방학 동안 해외여행을 떠나고 싶은 아현이. 조사해 보니 항공료, 현지 물가 같은 비용이 여행지 선택에 큰 영향을 준대요. 아현이는 예산, 이동 거리, 체험할 수 있는 활동을 모두 따져 자신에게 가장 알맞은 여행지를 고르기로 했어요.

관광 산업은 데이터 분석으로 빠르게 바뀌고 있어요. 한국관광공사의 데이터랩은 이동 통신, 신용 카드, 내비게이션 등에서 모은 빅데이터로 관광객의 이동 경로와 소비 패턴을 분석해 지역별 관광 전략을 세워요. 오늘은 우리도 실제 데이터로 유럽 배낭 여행지를 고르는 분석을 시작해요.

01

데이터 분석에 필요한 데이터는 무엇일까?

교과서 103쪽 · 유럽 도시별 숙소 정보와 고객 평가 데이터 · 유럽 도시별 생활비 데이터

쉽게 말하면분석은 질문에서 시작해요. 「싸면서도 만족스러운 여행지」를 찾으려면 숙소가 얼마인지, 손님들이 어떻게 평가했는지, 그리고 먹고 다니는 데 드는 현지 물가까지 알아야 해요. 그래서 데이터를 두 가지 모아요.
🏠

① 유럽 도시별 숙소 정보와 고객 평가 데이터

공유 숙박 플랫폼에서 숙소를 예약할 예정이므로, 그 플랫폼이 공개한 유럽 도시별 숙소 정보와 고객 평가 데이터를 모아요. 교과서는 데이터 공유 플랫폼인 캐글에서 Airbnb Prices European Cities(Merged)를 검색해 내려받아요.

우리가 쓸 파일: airbnb_european-cities.csv · 암스테르담, 아테네, 바르셀로나, 베를린, 부다페스트, 리스본, 런던, 파리, 로마, 비엔나 10개 도시
🛒

② 유럽 도시별 생활비 데이터

여행지의 물가를 알려고 세계 도시 물가 안내 사이트(NUMBEO)의 유럽 도시별 생활비 데이터를 모아요. NUMBEO는 사용자들이 제공한 데이터를 바탕으로 생활비, 범죄율, 건강 관리, 교통, 오염, 주거 같은 통계를 제공해요.

우리가 쓸 파일: NUMBEO 자료를 교과서 자료실에서 가공해 제공한 Europe Cost of Living Index by City 2024.csv (다음 시간에 써요)

캐글에서 직접 내려받으려면 계정이 필요해요. 우리는 선생님이 알려 주는 폴더의 파일을 써요. 생활비 데이터의 지수는 기준 도시(뉴욕)를 100으로 놓고 비교한 값이라, 100보다 작으면 기준 도시보다 물가가 낮은 편이에요.

🧭 이 질문엔 어느 데이터가 필요할까?

여행지를 고르며 떠오른 질문이에요. 어느 데이터를 보면 답할 수 있을지 골라요. 한 데이터로는 답할 수 없는 질문도 있어요.

🏠 숙소 정보 데이터의 속성 총 숙박비 · 객실 타입 · 숙박 가능 인원 · 청결도 · 고객 만족도 · 침실 수 · 도심 거리 · 지하철 거리 · 도시 …
🛒 생활비 데이터의 속성 생활비 지수 · 임대료 지수 · 식료품 지수 · 레스토랑 가격 지수 · 지역 구매력 지수 · 도시 · 국가 …
🔍 데이터 편향 떠올리기 숙소 데이터는 그 플랫폼에 올라온 숙소만, 생활비 데이터는 사이트에 값을 남긴 사용자의 정보만 담고 있어요. 분석 결과를 말할 때 누가 만든 어떤 데이터인지도 함께 밝혀야 해요.
02

숙소 데이터는 어떻게 생겼을까?

교과서 104쪽 · File · Data Table · Column Statistics(Feature Statistics) · 함께 해결하기

쉽게 말하면분석하기 전에 데이터를 훑어봐요. 몇 줄인지, 어떤 속성이 있는지, 빈칸(결측치)은 없는지, 평균과 중앙값은 얼마인지 보면 데이터의 특성이 보여요. 오렌지3에서 File → Data Table · Column Statistics로 확인해요. 교과서에는 Feature Statistics라는 옛 이름으로 나와요.

데이터 행 51,707개, 속성 15개예요. 범주형 속성 8개(room_type, room_shared, room_private, host_is_superhost, multi, biz, city, weekends)도 Missing은 모두 0이에요.

03

1인당 숙박비는 어떻게 구할까?

교과서 105쪽 · Formula 위젯으로 새 속성 charge 만들기 · Data Table로 정렬하기

쉽게 말하면2인실과 6인실의 총 숙박비를 바로 견주면 공평하지 않아요. 총 숙박비(realSum)를 숙박 가능 인원(person_capacity)으로 나누어 한 사람이 내는 값을 새 속성 charge로 만들면 크기가 다른 숙소도 비교할 수 있어요.

✏️ Formula 미리 해 보기 (새로 만든 예시 숙소 5곳)

charge 칸에 realSum ÷ person_capacity를 직접 계산해 적어요(소수 둘째 자리까지). 다 적으면 「확인하기」, 그다음 두 정렬 단추로 순서를 비교해요.

🔀 오렌지3에서 charge 만들기

번호위젯 (카테고리)어디에 연결설정 · 할 일확인할 것
4Formula (Transform)숙소 정보 →New → Numeric → 이름 칸에 charge

💡 식에 속성 이름을 직접 치면 틀리기 쉬워요. Formula 창의 Select Feature 목록에서 골라 넣고, 그 사이에 /만 쳐요.

Data Table (1)에서 찾아 적기

person_capacity는 숙박 가능 인원이에요. 그래서 charge는 그 숙소를 정원대로 꽉 채워 묵을 때 한 사람이 내는 값이에요.

🙋 스스로 해결하기 · 숙소와 도심과의 거리 (교과서 107쪽)

여행할 때는 숙소와 관광할 도심과의 거리도 중요해요. 오렌지3 Bar Plot의 Values를 dist - Mean으로 바꾸거나 위 탐색기에서 도심 거리를 골라, 숙소와 도심과의 거리가 가까운 곳과 먼 곳을 찾아요.
